# 45 提示准备前端切片

2026-09-11。基于 `923d365` 的独立前端切片 `feat/ai-prompt-workspace`。本记录是可交互页面与受控传输验证，不是实际模型、实际 worker 或完整 AI 能力的验收声明。后端配套为 `1d1b83a`，由主线程整合后验证实际 API。

## 已实现的用户路径

- 分镜的中央有界“本次创作输入”保存手工提示；非模态 AI 助手增加“准备提示”，用户明确选择镜头来源。两处复用同一份 session/project/shot 草稿，草稿内固定 `shotRevisionId`。导航与最新镜头版本不会替换已固定来源。
- 明确选择文本辅助模型、目标图像／视频／音频能力与修订，查看固定计划，再单独执行 `creative_assistance / prepare_prompt`。上下文仅为所选固定镜头与服务端解析引用，不隐式附带整场或整部剧。
- 无实际能力时显示缺少的条件并禁用准备。`executionMode=test_fixture` 的能力、计划和建议明确标注受控测试；没有预设答案作为真实模型返回。
- 任务以原 GenerationPlan/Job 身份保存，未知执行和刷新只读恢复；明确恢复沿用原请求身份，仍依赖服务端每计划唯一任务。人工继续编辑本次提示不会改变已创建计划。
- Job 的 `assistanceArtifactId` 打开独立建议；原始 r1 与保存后的历史修订只读可查。可修改提示、备注、保留和调整要求；实际参考仍以固定引用保留。编辑使用 `If-Match` 新建修订，不写入镜头要求。
- 编辑意图先保存在本机。丢失保存回执后先 GET 核对：仅当下一修订与所发正文一致才确认成功；原基线未变才开放按原 If-Match 显式重送。其他修订冲突不改变本机基线。用户可明确保留本机编辑副本，再打开最新修订核对。
- 应用前展示目标、现有原文与将追加的固定建议修订；确认时重新读取固定建议与当前镜头，拒绝已变更来源或过期确认。追加保留手工原文、固定参考与单一 `assistanceSource={artifactId,revision}`；同一次输入不会重复追加。另开一次输入须明确操作，并保留之前的原文和来源。
- 复用原 `AssistantSession` 的本机写队列、epoch、editing-lifecycle；权限提示立即隐藏，当前 session、固定镜头和已恢复建议 GET 核对后才展示，确认 401/403/404 后清理本机记录，断网保留隐藏副本。旧会话晚到返回不能写回或重现内容。

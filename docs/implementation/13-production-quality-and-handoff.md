# 13 制作质量、素材交接与实验记录规范

状态：首版实施规范与待执行模板，尚无真实样片或工作室通过结论。用于落实 [制作夹具 F0–F3](10-production-fixture.md)，不扩展为专业 NLE、发行系统或自动质量评分。状态、来源关联及 API 以领域／接口契约实现；本文件规定用户应能理解和验收的业务行为。

## 1. 开始一轮制作实验

使用 [实验计划与结果](templates/experiment-plan-and-result.md) 固定任务版本、质量依据、参考文件、生产路径、参与者、预算和停止规则。金额必须来自已授权的真实账号及测试预算，不设置虚构“推荐充值额”，也不授权自动购买新服务。

先区分三种结论：导入／构造媒体通过只能证明系统行为；指定账号实测才能证明该服务路径；工作室完成可比完整任务才能评价使用价值。同一个报告可以包含三者，但每条证据必须标明层次。

角色身份、服装造型、声音身份、当前剧情状态分别说明。每镜制作前能查看实际采用的依据；如场次默认与本镜要求相冲突，先明确采用哪个版本／状态。出口状态只代表期望，不由生成完成自动确认。

## 2. 《旧钥匙》的具体质量依据

以下关键错误与本片叙事有关，是本次样片标准，不能宣传为所有题材的统一行业阈值。任务版本改变时同步修订依据；例如 F2 把“昨天”改成“今天”的分支，应按新文本审阅，不能和原稿混用。

| 检查项 | 本片应成立的事实 | 阻止本版通过的具体错误 | 观察范围 |
|---|---|---|---|
| Q01 人物与造型 | 林夏、周衡可被持续识别；第一集及第二集即时接续使用原造型；次日上午才切到针织衫 | 身份误认、同一连续动作中无叙事依据换装、换装使角色声音身份意外改变 | 正面／侧面、表情变化、相邻镜头及跨集接续 |
| Q02 钥匙与行动 | 一把黄铜钥匙带红线；桌面 → 林夏右手 → 灰风衣右外袋 → 次日上午取出放桌上 | 钥匙复制、凭空消失／转手、取出来源不成立、手物接触造成无法理解的拿取 | 动作前后完整播放，不只看一张静帧 |
| Q03 空间与方向 | 桌子两侧人物关系可理解，走廊入口与所看方向对应；同一咖啡厅再用有依据 | 对话视线与位置互相矛盾、人物突然换边导致关系不清、门指向错误空间 | 建立镜头、正反打、转场、第二集返回 |
| Q04 台词与说话人 | 当前剧本中的“父亲”“昨天／今天”“别开”等关键内容准确，由对应人物说出 | 关键字错、漏句、重复句、张冠李戴；字幕与当前批准文本／实际声音冲突 | 逐句听看，核对当前台词及实际字幕 |
| Q05 声音与口型 | 可见说话动作与该句声音协调；跨镜声音完整，原轨和外加对白关系明确 | 双份对白、截字、错误静音、必要环境声突然消失、可见口型冲突未处理 | 含前后接点回放；正常播放判断，不把工程帧误差当表演标准 |
| Q06 反应与悬念 | 林夏在听到关键信息后反应；第一集没有开门；第二集明确时间变化 | 反应提前改变因果、补镜改变“没有开门”的事实、时间跳转不明导致造型／道具误读 | 场次连续播放和整集完整播放 |
| Q07 输出与配套 | 审阅对应实际文件；字幕属于该版本；交付规格与项目约定一致 | 错版本、字幕错配、缺素材仍宣称完整、无法完整播放或输出被截断 | 实际下载文件、SRT 与清单共同检查 |

景别、运镜、表演强弱与节奏可按参考样片讨论，不强制每镜统一形式。不能为了让测试通过而把写实口型、故事因果或道具错误改称“风格”。若确需改变创作要求，保存新的任务版本及原因，再按新依据审阅。

非关键瑕疵可以被负责人明确接受，但应记录本版例外、理由和实际影响。关键事实未达成则本版需修改；不得用平均分稀释，或将“需要局部修复”直接当作最终已合格。平台不自动裁定内容通过。

## 3. 审阅和返工的最小记录

使用 [质量与返工记录](templates/quality-and-rework.csv)。每条问题记录实际观看对象及版本、时间范围、关联镜头／台词（已知时）、看见／听见的错误、期望变化、必须保留项、选择的修复路径和复查结果。未知外部映射保持未知，不能通过相似画面自动填入镜头身份。

返工默认复查目标区间及前后两个接点，再完整看对应场次；涉及台词时核对声音、字幕、说话人和可见口型。整集最终批准前完整播放实际文件，不能仅凭每镜候选曾通过批准整集。相同长度改词仍需检查直接关联的声音／字幕；变句长还需检查后续时序，不自动移动所有下游。

意见处理完与正式批准是不同事实。旧意见和旧批准继续属于原文件；新候选不继承批准。所有外部修复或工程人员代做都要记入主动人工，不能将操作转移到软件外就视为成本消失。

## 4. 三种素材包的业务约定

### 4.1 只有采用时的原素材包（source package）

原素材包属于工作材料，可以在只有镜头采用、尚无平台剪辑、渲染或审阅时导出。创建包时固定本次选取范围、采用记录、源媒体与区间、制作要求版本及说明；此后当前采用改变不改写旧包。没有采用或没有足够可用素材时明确列出缺项，不制造空结果宣称完成。

必须包含：选中采用所依赖的完整原素材、可读镜头／区间表、已知声音／字幕关系表、JSON manifest 与简短说明。没有剪辑时明确写“无平台剪辑、无时间线、无平台预览；排列仅为制作规划”；没有正式批准则标记工作材料。不得伪造 cut、审片、成片或批准者，以便满足导出流程。

可以显式选入 SRT 等补充媒体，记录它是供哪个已知版本／范围使用或仅作参考；未知适用范围如实标记。不能自动从其他剪辑稿借字幕，也不能因包内有 SRT 就宣称存在平台时间线或已完成字幕核对。加选文件及其版本同样进入本包固定清单。

原素材包的接收目标是识别采用意图、文件及源区间。它不能证明接收者能重建一份从未存在的时间线，也不是可直接交付观众的成片。

### 4.2 有剪辑版本的工作包

固定一份已知剪辑版本，带上该版实际预览、已知时间线、完整原素材、SRT（实际存在时）、可读镜头表、声音／字幕对应表和 JSON manifest。平台预览尚未渲染好时如实标记；可以先输出已就绪的工作材料，但不能标成“预览齐全的工作包”。冻结时间线与预览必须匹配。

镜头表一行代表一次实际使用，因此同镜头或同媒体可以出现多行，包括不连续区间。表明集场镜标签和稳定身份、候选／采用依据、源文件、源入出点、剪辑入出点、帧率、原轨是否播放，以及声音／字幕关系。镜头当前偏好候选与实际剪辑使用不同也要如实写出，不能用当前指针覆盖冻结版本。

前后可用余量默认通过完整原素材保留，不在首版建设复杂 handles 设置。源视频本来没有额外帧时如实标记，不能补帧充当原片余量；如另行提供裁切代理，必须标记其派生性质并保留对应原文件。

### 4.3 最终交付

最终交付只能来自该具体整集或外部成片版本的正式批准，并固定实际成片、实际配套字幕、输出规格、确认记录及清单。工作材料可以提前导出，不能获得“最终已批准”标签。已批准但有新草稿时，导出仍明确显示批准版本；新版本需要新审阅和新交付。

### 4.4 所有包共用的文件和清单规则

两类工作材料包首版默认提供完整、可用的原素材；最终交付是否附原素材按本次交付约定。在同一包内按已验收内容校验值去重，一份实际文件可以对应多个媒体／候选／镜头引用，映射全部保留。不得因为同一源视频用了三个区间就复制三次文件或计算三次源作业费用。不同文件即使名字相同也不能覆盖；文件名由系统安全生成，并保留可读标签到实际文件名的映射。

JSON manifest 记录：本包目的及版本；固定的内容／采用范围；有无剪辑、预览、时间线和批准；文件相对路径、角色、校验值及大小；已知源区间和剪辑使用；声音与字幕关联；缺项、未知项和生成包的时间。精确字段以统一交付契约为准，不在本文件另建不兼容 JSON 格式。manifest 不把自身纳入循环自校验；包校验值由交付记录保存。

时间记录保留实际源入出点和帧率，说明采用半开区间及实际归一后的边界；人可读表同时提供秒值或时间码，不能把微秒当帧号。未制作时间线时，剪辑入出点留空并写明未建立，不能填 0 假装知道。字幕说明是可选烧录还是独立文件，避免后期重复烧录。

声音表明确每段来自视频嵌入混合轨、独立对白、环境声、音乐或其他已知来源；记载视频原轨保留／静音、独立声音的源区间与剪辑位置、关联台词及字幕。取出视频中完整音轨仍是混合轨，不声称获得人声净轨。角色声音身份与某一次实际台词录音分别说明。

模板：[镜头／区间交接表](templates/shot-handoff.csv)、[声音与字幕关系表](templates/dialogue-sound-subtitle.csv)、[交接接收记录](templates/handoff-receipt.md)。模板是可读工作材料，不能替代服务端清单、授权校验或媒体检验。

## 5. 外部 MP4 与 SRT 回传

接收外部成片时，登记本次回传关联的工作包（已知时）、MP4 与可选 SRT，并把每份文件及校验值固定到同一外部版本。独立 SRT 需通过格式、时间范围和编码校验，再由人对照实际声音／画面确认；解析合法不等于字词和时序正确。片长外字幕、不属于该成片的字幕或不完整文件应明确返修。

同一外部 MP4 后补或修改 SRT 时，形成可区分的新外部交付版本／配套组合并重新确认，不能覆盖已批准组合。缺独立 SRT 时标记缺失，不默认沿用旧平台字幕，也不以空 SRT 补齐。

外部成片及 SRT 只能证明这两份文件的内容和对应关系。没有可信工程资料时，外部时间线、最终逐镜来源和工程可重建性均保持未知；字幕时间码、文件名或旧工作包不能推断出工程映射。意见基于回传 MP4 自身时间，接手者可人工注明已知来源并说明依据。

F3 的接收者应是未参加该段原制作的内部后期人员。记录其现有软件、重建范围、实际耗时、缺素材／缺说明和额外帮助，完成实际改接点、改字幕及回传。首版允许人工重建，不承诺 NLE 工程一键往返。

## 6. 制作成本与人工口径

用现有账本作为源证据，模板只做实验汇总，不另造第二套扣费事实。

| 记录 | 口径 | 模板 |
|---|---|---|
| 一次性准备 | 本次两集共同使用的剧本整理、身份／声音／空间参考、上手与流程准备；不反复分配成两份实际支出 | [人工记录](templates/labor-log.csv)、[非作业费用](templates/non-job-costs.csv) |
| 第一集与第二集增量 | 在固定起点后各集新增的制作、挑选、剪辑、审阅和返工；第二集新增资产也计入增量，不能因“可复用”漏记 | 同上 |
| 作业费用 | 每个 job 在当前汇总中只有一行，保存所有收费／调整证据的净额；同一媒体多区间复用不新增消费 | [作业费用登记](templates/job-cost-register.csv) |
| 未决金额 | 在途预占及已发生但未核清事项单列；已结算部分不再保留为相同金额的未决占用，未知不写 0 | 作业费用登记 |
| 非作业费用 | 录音、外部软件／服务、素材采购、存储、转码、渲染及下载等真实支出；能确定已在 job 账中计入的费用不再加一次 | 非作业费用 |
| 协助与外部处理 | 负责人指导、工程代做、后期修复、解释和接手的每个人主动分钟；包含“免费帮助”的工时，实际现金无支出可以明确说明 | 人工记录 |

同一人的同一时间不能重复计入两项主动工作；多人同时协助可以分别计人时。异步模型等待、排队和日历周期分别记录，不把团队主动分钟相加当交付周期。人工分钟与现金分别报告；若要折算人工现金成本，必须说明实际采用费率及其来源，不能把推测工资当实际支出。

结果同时报告：一次投入、第一集增量、第二集增量、两集合计主动人工、已确认现金、未决金额、外部帮助，以及从任务开始到批准的日历周期。实验剩余预算以真实账本为准；已确认现金与未决占用可以形成风险敞口，但不得一起命名为“已花费”。

只有达到同一预定标准的成片才能进入“每分钟合格成片”辅助指标。两集小样不能推断长期摊销；失败路径保留全部投入，并报告在何种资源范围内未完成。不同币种不直接相加，费用修正保留依据。对照任务说明素材是否预先准备、哪些在两条路径共享以及执行顺序，避免把学习或额外帮助当产品收益。

## 7. 实验停止与改路径默认规则

以下数字是首轮受控实验默认值，**不是行业产能标准、产品调用限制或预算授权**。负责人可在实验开始前按任务调整并记理由；不能看到结果后回改目标掩盖失败。金额约束始终取已授权真实账号、项目及本轮实验预算中的适用上限，较早到达的限制优先。

| 触发 | 默认动作 | 必须留下的记录 |
|---|---|---|
| 同一明确问题、同一制作路径连续最多 3 次新付费尝试仍未达到该项质量依据，或该问题在此路径累计主动处理 60 分钟仍无可用方案，以先到者为准 | 停止该路径新增付费尝试，检查失败原因；选择补镜／已授权另一条路径／外部修复，或结束该项。已有结果继续归档 | 实际尝试、主动分钟、失败类型、为何换路径；重试编号不能因换成员或改提示词清零 |
| 同一问题已尝试 2 条明确路径仍未通过 | 本轮停止该问题的新生成，报告未完成及所需条件；不新增第三个服务继续碰运气 | 两条路径的质量、成本和人工结果；可接受的剩余交付范围 |
| F0–F3 合计主动人工达到 16 人时；真实连续两集试点每项任务的每次流程执行（首期工作台；后续配对时分别记录）达到 32 人时，以实验计划记载的调整值为准 | 完成当前结果归档和记录，停止本轮新增制作，报告已完成与未完成。后续另立有范围的实验，不能把超额工时移出本轮 | 含一次准备、协助、后期和返工的累计主动人工；归档收尾工时另外如实追加 |
| 下一次计划可能超过本轮已授权可用预算；估计依据失效；账号条件未落实 | 不提交。继续可逆的资料整理／已获得素材检查，必要时记录本轮无法继续 | 原预算、已确认支出、未决占用、计划估计及阻断原因；不充值或购买 |
| 提交结果／费用无法核清，或出现重复收费、无法及时归档的可信风险 | 暂停受影响连接的本轮新提交，先核对原任务；不为维持实验进度重买同一意图 | 待核对证据和归档状态；不得将未知费用记 0 |
| 预定质量无法在已用两条路径或剩余资源内达到 | 结束本轮并报告“在本轮条件下未交付”；若缩小创作要求，另保存任务版本后再评价 | 原目标、实际结果和范围改变，不能把未完成秒数算合格成片 |

“路径”按操作办法区分，例如原生音画重做、独立声音加补镜；简单更换提示词不是新路径。若第一次输出已满足要求，直接采用，不为耗尽实验次数额外购买。准备图片、音频、文本分析、媒体处理等收费同样计入真实预算，不得藏到“上传”或“协助”中。

停止规则只管本轮实验，不自动取消可能已付费的在途任务，不删除失败结果，也不改变平台允许的常规人工操作。停后仍应完成核账、归档、说明和证据保存；其实际工时继续计入结果。

## 8. 证据包与关闭条件

每次工程或真实试点输出：已填写的实验计划／结果、实际媒体和版本清单、质量与返工记录、镜头和声音交接表、人工与费用表、接收记录及缺陷清单。空模板、示例编号和构造信号都不能算已执行证据。

F0–F3 按 10 §6 分项关闭；真实每集 60–120 秒的连续两集按 10 §7 单独评价。未解决的关键剧情、音画、版本错配或工作包缺失问题保留为未通过；可逆研发不必等所有市场问题关闭，但不能提前将工程夹具结论升级成稳定量产或工作室价值证明。

## 9. 场次交付补充

场次可进入整集的完成定义见 [14 §1](14-scene-mvp-closure.md#1-范围与完成定义)：正确正式对白、基本声画和必要声音字幕、连续观看确认及完整来源材料。场次和整集批准独立；整集包包含已知平台场次依赖，外部未知来源如实列出。首期按 12 验证工作流承接，不设固定人工／费用改善比例门槛。

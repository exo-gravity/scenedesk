# 镜头列表：稳定切换与有界预览

2026-09-17，用户报告点击镜头时页面闪动，并明确要求左侧列表可以滚动、整个弹窗没有外层纵向滚动条；由实施方独立判断具体布局。

## 原因与修复

原弹窗由内容撑开。切换到未缓存镜头时，按镜头身份重建的候选预览会先返回一个 Loader；内容高度降低后，居中的 Modal 重新计算位置。1366×768 生产构建复现中，预览和列表从 696px 缩到 440px，弹窗顶部由 38px 移至 53px。视频加载完成后再次撑开；不是整页导航或重新加载。

保留按镜头身份隔离的预览、确认和草稿状态；通过稳定容器解决布局跳动，不通过复用上一镜头的结果冒充新镜头。候选、固定要求与权限错误继续在当前对象上明确显示。

## 布局与交互

- 弹窗最大宽度 1320px、高度不超过 900px，适配视口并保留边缘空间；标题、关闭和场次工具栏固定，外层不滚动。
- 左侧列独立滚动镜头顺序和排序操作，底部提供本场已选用原片交接；展开的交接清单在本地面板滚动。
- 右侧上方是当前镜头、可展开的完整说明、预览和比较候选。视频完整画幅适配剩余空间，加载、空态、错误和比较不会改变弹窗几何尺寸。
- 选用、清除及原片下载位于预览下方。候选说明、选用历史按需展开；候选登记和选用确认使用右侧局部表单区。新建镜头也保留左侧列表，离开前继续保留输入。
- 820px 保持两列；手机窄屏将列表置于预览上方并限定高度，预览与主要操作仍处于弹窗内。长列表、说明、表单各自滚动，不能通过裁掉控件消除滚动条。
- `MediaPreview` / `MediaPlayer` 增加明确的 `fit` 布局参数；默认使用方式保持原尺寸规则。没有更换播放器、删除恢复逻辑或修改媒体文件。

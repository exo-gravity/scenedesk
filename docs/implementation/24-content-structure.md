# 剧本与手工集场镜实现

本切片接续已合入的身份／项目基础。业务入口在项目设定页的“进入剧本与集场镜”，数据库迁移为 `0004_content.sql`；已应用的迁移内容不修改。现有本地环境执行 `npm run upgrade:business`，追加表与明确列授权，不覆盖身份或轮换凭据。

## 已实现行为

- 剧本保存为不可变版本，当前指针与内容根在同一事务更新。显式父版本须为当前剧本；旧镜头继续引用原版本。支持契约规定的 500,000 Unicode 码点，文本请求体上限单独适配转义后的字节长度。
- 集、场、镜新增共用 ContentTree CAS；对象更新使用自身 CAS 并递增内容根。项目锁序列化结构写入，幂等回放仍重新授权。操作成功、来源关系和审计同事务提交。
- 镜头身份、显示编号、排列位置与要求修订分离。改名、重排、归档不创建新要求；要求变化追加 shot revision，同事务生成台词行与显式剧本／来源镜头关系。历史表与投影不可更新、不可删除。
- 原文引用以 Unicode 码点半开区间保存，并核对原文与 quote。引用必须属于本项目；台词 ID 在同一修订内唯一，衍生台词须来自本镜历史或明确来源镜头。复合 FK 阻止把同工作室其他项目的父对象或历史混入。
- 内容按 position＋ID 显示；重排必须提交同一父对象的完整集合，包含归档项，不能带入其他父对象的 ID。归档不删除下级数据，父对象归档期间下级只读；恢复后历史继续存在。
- 页面提供剧本录入／历史复制、集场镜编辑、台词、连续性说明、原文选取与要求历史。IndexedDB 按用户／资源路径／标签页保存未提交内容，恢复由用户选择；保留原基线，服务器改变后明确核对再保存。恢复不自动提交。
- 列表分页修正为 createdAt＋ID；签名游标保存 PostgreSQL 微秒精度并绑定用户、项目、筛选与镜头路径，防止漏页及跨镜头游标重用。

# 已确认设计的业务页面还原

日期：2026-09-12。用户指出视觉设计、页面结构与布局偏离已确认方案，并要求严格按计划实施。本轮是把已经确认的方案落实到真实业务页面，不重新选择视觉方向。

## 偏差及原因

业务页面此前独立组合了宽侧栏、较大页边距、通栏表单和重复卡片，没有把 v0.3 原型的空间关系同步到真实工作区。根主题已经使用中性明暗色表，因此只替换颜色不能解决问题。此前的 `ui:check` 检查组件库、主题 token 和部分对比度，浏览器检查偏重业务行为与溢出；这些都不等于已确认布局的视觉验收。进度报告漏列了这项未完成工作。

本轮依据：[已确认基线](../design/approved-baseline-2026-09-10.md)、[核心体验 v0.3](../design/scene-walkthrough-review-v0.3.md)、[专项 v0.4](../design/production-detail-design-v0.4.md)、[共同视觉语言](../design/shared-visual-language-v0.1.md)。已后置的剪辑、交付、完整团队及运营能力不恢复到首发入口，保留能力的结构与视觉要求继续适用。

## 还原与验收范围

| 页面／状态 | 按已确认方案实现和检查的关系 |
|---|---|
| 全局与项目目录 | 34px 顶栏、76px 工作室导航、56px 上下文栏；项目目录在上下文栏下，宽196px；制作、剧本及资产详情释放项目目录空间 |
| 项目首页／我的工作 | 项目画面与名称构成入口，没有图片时明确空态；我的工作读取当前账号的真实创作任务，使用平行行，不重新开放团队管理 |
| 场次目录 | 单集分组、平行场次行、制作入口；编辑与排序就近展开，避免把全集镜头要求常驻堆满目录 |
| 剧本与设定 | 正文是主区域；历史和固定原文可查；分镜建议、修订与明确采纳使用按需辅助区域，原持久草稿和冲突保护保留 |
| 分镜 | 当前镜头大媒体预览、中央有界提示输入、底部缩略分镜条；候选与素材按需打开，和助手协调占用空间 |
| 自由画布 | 全场空间、左下悬浮视口工具、就近添加菜单与有界输入；媒体采用轻标题，节点坐标与镜头顺序分离，保留视口与编辑恢复 |
| 助手 | 非模态停靠，明确上下文与固定目标，默认收起；保留建议修订、生成确认、未知提交与结果恢复 |
| 资产／素材 | 固定版本与引用可扫描，媒体占主体；详情恢复专项左右关系，避免重复导航和层层卡片 |
| 明暗与紧凑视口 | 同一中性色表和结构；使用媒体6px、工具8px、浮动输入12px语义圆角；明暗不改变媒体颜色 |

## 验证记录

本轮保留页面的结构、明暗样式及核心交互已完成生产构建浏览器验收，交付 [PR #33](https://github.com/exo-gravity/scenedesk/pull/33)。合并及最终远端检查状态以该 PR 为准。

- `npm run check` 通过：契约、UI规则、双 TypeScript 项目、生产构建与 144 项单元检查。最后的局部播放器 CSS 修正另经 UI 与生产构建验证；文档设计检查通过。
- [最终整合截图与记录](../../output/playwright/2026-09-12-approved-integration/README.md)：在统一业务构建中逐页操作，检查 1512×982、1366×768 的同尺寸布局，并补查 390px 窄屏边界。剧本辅助栏为410px／370px；资产栏及场次助手为360px。明暗切换不改变媒体颜色。
- [场次与剧本专项](../../output/playwright/2026-09-12-approved-content/README.md)：合成 HTTP 故障下的创建未知回包、保存成功后读取失败、提案编辑和明确采纳。最终整合另用真实 API／数据库核对剧本跨页保留和刷新后明确恢复，原草稿内容完整。
- [场次制作专项](../../output/playwright/2026-09-12-approved-scene-layout/README.md)：真实受限 API／数据库的画布保存、模式切换和刷新；无画布与空候选入口；手工输入、互斥侧栏和固定参考。媒体采用本地静态测试适配器，不作为对象存储或真实模型验收。
- [资产与媒体专项](../../output/playwright/2026-09-12-approved-assets-assistant/README.md)：真实 PostgreSQL／MinIO 的预签名上传、探测与派生图，固定 v1／当前 v2 切换、编辑草稿恢复、明暗及完整原图展示。隔离媒体夹具显式使用2GiB测试卷；默认测试容量与生产阈值未改。

最终比图还修正了竖屏播放器外框过宽、控制条换行裁切，以及画布工具误置于顶部的问题。最终真实播放完成4秒，播放／静音／全屏按钮均位于播放器内，五张已采用缩略图加载完成。截图中的测试媒体与身份明确标识；没有为凑齐原型内容伪造生产候选、模型或版本状态。

真实模型 transport、真实部署／身份验收以及模型执行恢复门禁的既有缺口独立保留。视觉修正不把本地模型 fixture 等同于真实 AI，也不把布局还原等同于整个 MVP 已完成。

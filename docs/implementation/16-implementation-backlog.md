## 4. 每个工作包的完成定义

数据迁移与约束、对应接口和授权、可操作页面、异常恢复、必要的跨模块测试、实际演示证据一并交付。生成 Schema、Mock 通过或路由返回示例 JSON 都不是业务完成。复杂媒体和费用路径必须有真实数据库／媒体或供应商证据，不能用镜像实现的单元测试代替。

每次修改主稿范围时同步 01/02/03/06/08/14、OpenAPI 生成器及样例；已冻结历史评审不改。新版本要保留旧稿、原字节、采用和费用来源，不为通过演示删除失败记录。

## 5. 本期不展开的能力

任意自动执行节点流程、实时共同编辑、任意 Agent 编排／Skills 平台、全自动整剧、专业 NLE 往返和深合成、广告业务入口、Guest／客户公开审片、自定义复杂权限、发行投流与自动充值。它们保留在 09 的后续计划，不阻断已定 MVP。

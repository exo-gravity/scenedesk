当前范围依据[38 当前 MVP](38-first-release-scope-review.md)。画布与 AI 保留原方案，后期处理不再是发布依赖。GitHub 组织于 2026-09-11 按用户变更改为 `exo-gravity`，当前仓库为 [exo-gravity/scenedesk](https://github.com/exo-gravity/scenedesk)，已有 [PR #16](https://github.com/exo-gravity/scenedesk/pull/16) 延续。本文记录 `feat/scene-canvas` 的实际进展；已接通 CX01 的服务基础、CX03 镜头关联与独立探索，以及部分 CX02／CX06 页面恢复，尚不是完整画布业务交付。

## 已实现的服务基础

接通 `ensureSceneCanvas`、`getSceneCanvas`、`getCanvas`、`saveCanvas`、`getCanvasRevision`、`listCanvasHistory`、`getSceneWorkspacePreference`、`saveSceneWorkspacePreference` 八个既定操作。读取不创建画布或偏好；明确进入时并发请求仍只创建一张场次画布。画布引用真实场次，所有访问使用当前项目授权、会话和 CSRF 检查，幂等重放仍重新授权。

迁移 0017 增加通用画布根、场次接入、不可变修订、节点身份墓碑、类型化媒体／资产引用、私人视图偏好及同事务失效通知记录。画布文档不依赖镜头和剪辑。画布正文采用独立的类型化 `canvas_history_bodies`，复用 `editing-json-v1` 编码与现有有限历史策略，避免改写已应用的 Cut 外键与历史正文。正文按 hash 去重，数据库校验实际 SHA-256；修订只能在对象锁内追加，当前和前一版不能删除。未来真正需要完整修订的业务引用须加入类型化 pin；生成来源另存确切输入，不能默认把所有完整历史永久保留。

整个文档按 If-Match 保存；冲突返回 412 和当前修订，相同内容重送不追加伪历史，但仍核对引用权限。接受不完整提示和模型选择草稿，不执行模型。文字、媒体、草稿节点、引用边和分组遵循原数量／UTF-8 字节上限；引用只能从文字或现有媒体进入草稿。节点种类和媒体身份一经建立不可替换，删除后恢复仍检查墓碑。原有且仍授权的归档素材可在当前节点保留／移动，复制或重新引入需可用素材。固定资产版本必须实际包含所引用媒体；不能用外项目素材伪造引用。

历史列表使用用户／项目／画布绑定的游标，并按当前保留策略过滤。超过保留期返回 410；保存时在同一对象锁内清理修订、无引用正文及其类型化投影，节点身份不随历史清理消失。个人模式、选中和视口使用独立 CAS，首次版本为 0，不增加公共画布修订；RLS 限制只能读取本人偏好。

## 镜头关联与独立探索（2026-09-11）

迁移 0018 和既定 `bindSceneCanvasNode`／`unbindSceneCanvasNode` 操作接通真实关系。场次读取返回当前绑定及节点是否仍在画布中。参考只建立待选关系；视频候选在同一事务内按固定镜头要求、媒体和微秒区间创建或复用 Take，保留原候选说明与来源，不改写镜头默认参考或当前采用。一个节点可明确关联多个镜头，也可同时有参考与候选关系；已有关联不能被另一版本或区间静默替换。

绑定使用画布 If-Match，与文档保存竞争同一修订。数据库独立验证真实场次、当前媒体节点、镜头版本、可用媒体和固定资产版本；受限 SQL 写入同样推进画布修订并记录 outbox，复用原正文 hash。节点移除保留绑定历史，撤销／取回节点使关系再次可见；复制产生独立节点。明确解除只删除指定关系，保留候选、素材及采用，画布撤销不回滚这些外部事实。迁移 0018 已在本地运行库应用，后续修订须新增迁移。

制作页增加单一停靠的“本场镜头与探索”：查看本场关联、定位节点、切回分镜，以及明确把已有候选或固定镜头参考添加到画布，再核对关联。未关联的文字、素材和草稿有独立探索入口。表单固定打开时的目标；滚动时标题持续显示该目标。候选区间保留原始输入，跨模式／刷新恢复；已有候选带入后，即使未继续编辑也持久保留其版本、范围和来源。提交前持久保存输入；丢失成功回包后先读取真实关系和候选，核对一致便结束，不重复 POST。解除确认绑定当时画布版本，期间另有编辑即停止旧确认。

## 编辑者提示与项目通知（2026-09-11）

迁移 0019 接通既定 `getEditingPresence`／`updateEditingPresence`。目标通过实际 Canvas／Cut 外键定位；本人身份来自当前登录，服务器给出 90 秒有效期。每成员每目标最多 5 个客户端、每目标最多 500 个客户端，短事务锁串行检查容量；心跳不增加内容版本或审计记录，也不阻止其他页面写入。归档目标允许查看，编辑心跳被拒绝。退出、成员／项目权限撤销主动清理所属会话提示，读取或心跳清理该目标的过期／失效项。新登录接管同一客户端后，旧心跳不能覆盖新登录，旧会话退出不能删除新会话记录。没有全库定时清扫器，未再访问目标的过期行仍待后续维护清理。

迁移 0020 接通既定项目 SSE。现有画布 outbox 与项目、内容、镜头、资产、媒体、候选、采用、人工任务、提案和旧工作稿的已提交变更生成不含正文的提示。按项目串行 relay 分配独立序列；不使用生产事务开始时的序号，且即使受限 SQL 在生产事务内调用 relay，也排除自身未提交记录。当前实现由有权连接按需拉动每批最多 200 个资源，没有额外常驻 relay 进程。离线期间 outbox 保留，首次连接发送 reset 后刷新快照；提示是失效通知，不是逐次业务操作日志。

事件保留最近 24 小时且最多 10,000 条，relay 时清理；过期／超前游标返回 reset，序列使用十进制字符串。连接每 2 秒重新验证当前登录及项目授权，不持有长事务；退出或撤权发出 access_revoked 后关闭。每 API 进程限制同一用户／项目 5 条流、项目 500 条流，尚非多实例全局配额。慢连接等待排空，超过 5 秒关闭；每 15 秒发送保活注释，应用关闭主动结束连接。实现参考 [Fastify hijack](https://fastify.dev/docs/latest/Reference/Reply/) 与 [EventSource 游标规范](https://html.spec.whatwg.org/dev/server-sent-events.html)，不是 WebSocket 共同编辑。

项目页面共用一条 EventSource，通知合并为当前资源重查；连接、登录变化和错误后用 GET 重新核对。画布沿用原恢复控制器，通知只触发读取，版本落后不能覆盖新状态，dirty 文档／原始输入保持并进入冲突比较。画布页每 30 秒发送 viewing／editing 心跳，活动改变串行补发；离开停止请求，根据服务器时间及本机单调时钟逐页移除过期提示；未收到后续状态时不宣称确定无人编辑。页面以短状态文字显示其他页面活动及通知连接状态；断网明确显示编辑状态暂不可用。

## 继续创作与多份参考（2026-09-11）

单选已有文字或固定媒体后可“继续创作”，多选后可“共同作为参考”；节点列表也支持 Shift 多选。短弹层列出打开时选定的来源，再由用户选择图片、视频或声音草稿。创建动作保留来源，添加一个独立草稿和按选择顺序排列的引用，不继承镜头绑定，不执行模型。文字默认用于提示、声音用于声音参考，其他媒体用于构图；创建后可逐项调整用途和启停。

打开弹层时固定来源身份与内容；其他布局或无关编辑可以继续推进，来源已改动、移除或存在未完成原始输入时，旧操作停止并要求重新选择。未完成的生成草稿不能成为来源，创建仍遵守画布容量和关系约束。整次草稿及引用创建进入原画布保存／恢复与撤销系统；重复点击不能再次创建同一草稿。

本地完整 `npm run check` 通过契约、UI 规则、类型、生产构建和 48 项单元测试；新增三项行为测试覆盖原来源保留、有序独立草稿、固定来源变化、重复创建和容量限制。生产浏览器连接真实本地 API／PostgreSQL，验证单来源与文字＋媒体多来源创建、引用用途／停用保存、模式切换与刷新恢复、另一页实际修改来源后旧操作被阻止，以及创建的原子撤销／重做。没有生成请求，页面错误为 0。

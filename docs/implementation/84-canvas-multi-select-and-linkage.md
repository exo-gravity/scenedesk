# 84 画布第 1 步剩余部分：多选批量与画布—候选衔接

日期：2026-09-20。来源计划：[画布后续能力 review](../research/2026-09-18-canvas-next-capabilities-review.md)（定稿）第 1 步。

**本工作项只覆盖第 1 步的 #2 与 #3。** #1（批量生成）已由 PR #63 合入 `main`。

## 1. 为什么这三项是一体的

定稿计划的判据是**粒度**：短剧主链路（生成 → 组织 → 比较 → 选用）原本一次只处理一个镜头，而**场次连续性不可能在单镜头内判定**——任何一个镜头单独看都是"对的"。所以第 1 步要把粒度改粗。

三项的分工：

| # | 能力 | 现状 | 缺了会怎样 |
|---|---|---|---|
| 1 | 按场次／所选镜头的批量生成 | ✅ 已合入（PR #63） | 批量无从谈起 |
| **2** | **镜头列表与候选的多选与批量动作** | ❌ 未做 | **批量生成出来的东西还得一个个看** |
| **3** | **画布 ↔ 镜头 ↔ 候选 的明确衔接** | ❌ 未做 | 画布与选用之间的断点一直存在 |

## 2. 范围

### #2 多选与批量动作

- 镜头列表：多选镜头 → 批量生成（进入既有的 N 项确认屏）／批量查看候选
- 候选：多选候选 → 批量比较、批量归档
- **共享同一套选中语义**：两处的多选应由同一个选中模型驱动，而不是各写一套

### #3 画布 ↔ 镜头 ↔ 候选 衔接

- 画布结果能**一键进入候选**
- 能从候选**跳回来源节点**（画布上的生成现场）
- 反过来从候选能定位到画布

**不做自动采用。** `CanvasShotConnections.tsx` 已确立「候选与采用保持分别处理」，这是既定边界。领域上「可用素材／候选选用／明确采用／成片使用」是四个不同事实。

## 3. 硬约束（落地前必须遵守）

### 3.1 多选工具条不得直接触发付费批量执行

`docs/implementation/18-canvas-workspace-contract.md:25`：「多选 ── 移动、删除呈现、分组、共同作为参考；**不批量展开输入框、不一键执行多个付费任务**」。`docs/design/core-workspace-recommendation-v0.2.md:119` 同义。

批量的触发面必须是**多选之后的 N 项明细确认屏**，沿用 #1 已建立的模式：

| 允许 | 禁止 |
|---|---|
| 多选工具条只提供「查看 N 项的生成计划」这类**导航动作** | 工具条上直接「批量生成」把 N 个任务发出去 |
| 确认屏内展示逐项输入、逐项阻断原因、合计、逐项计划身份 | 工具条上批量展开 N 份输入框 |
| 确认屏内显式确认后执行 | 任何自动采用或自动进候选 |

依据：`01-product-requirements.md:50`（批量 UI 可以创建多个独立计划）与 `docs/design/model-integration-architecture-v0.1-2026-09-15.md:312`（编排成一个 `GenerationBatch` 下的多个固定计划／作业；**批次只是分组，不是第二套调度**；部分成功时保留成功结果，不重跑整批）。

### 3.2 费用只能如实显示

后端**没有预算机制**，只有配额闸门（`generation_submission_allowed`：`daily < max_daily_jobs`、`pending < 100`）。当前适配器的估价是硬编码的零，且插入后不可变。

- 「合计估价」目前只能是 **0 CNY**，并沿用 `model.ts` 里 `basisNote` 的诚实写法
- **不得为填满面板而编造价格**
- 提交前校验该挡的是**配额、能力失效、参考素材未验收、画布版本漂移**，不是预算

## 6. 与素材库（问题 02）的耦合

`output/reviews/2026-09-18-workspace-usability-round-2/README.md` 记录：画布 dock 里的素材浏览器读的是资产库同一份 `Media`，且**目前单选**。所以 #2 的多选语义与素材库的改造共享同一块地，实施时先确认由哪一侧先落。

## 7. 拆分判断

「多选 → 批量动作 → 衔接」是一次选中、多种去向，属**一个可独立审查的切片**，因此合为一个 PR。

**唯一例外**：若 #3 的落地需要**新的领域对象或持久化**（例如记录"候选来源节点"），那已经超出「多选」的延伸范围，应拆成第二个 PR。此判断在实施中做出，不预设。

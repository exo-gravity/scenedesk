# 分镜台：预览、候选与连续创作

2026-09-14。用户明确将分镜模式命名为「分镜台」，并要求 review 核心交互与信息布局、落实更优雅的体验。延续已确认的中性主题、媒体优先与中央有界输入；`storyboard` 路由及业务术语不改。

## 评审结论与实施

- 原页面默认同时展开参考和 208px 创作输入，在 1280×720 上把竖屏视频压到很小；主区还重复显示采用状态。现在常态突出完整画幅，底部输入默认收起并显示已有提示摘要、保存状态、错误与提示准备任务；明确展开后编辑，生成类型开启时获得更多空间。输入居中限宽 960px，不使用悬浮阴影。窄屏允许主内容自然滚动，避免展开输入时裁断视频。
- 参考、候选、素材及候选意见按需使用同一辅助面板；与外部 AI/素材侧栏互斥，保持主预览空间。打开辅助面板聚焦关闭入口，Esc 返回触发控件；内层下拉框的第一次 Esc 只关闭自身。参考修订重取失败时不继续渲染缓存的固定参考，保留错误与重试入口。
- 候选列表用真实海报、素材名称、固定区间辨认；当前候选下只显示一次采用状态。浏览候选 1 时若实际采用候选 2，会明确显示「当前采用：候选 2」，采用仍须确认。另选区间、候选意见就近进入更多菜单，清除采用保留在镜头更多菜单。
- 镜头条按 `position` 排序，当前镜头自动滚入可见区域；上一镜/下一镜、方向键、Home/End 和独立全场总览入口均可用，最后一镜不会被总览按钮盖住。总览隐藏主编辑区域、暂停其媒体而不重置时间，并把焦点移入；Esc 返回原入口。
- 原镜头链接绕过本机草稿保留屏障。所有工作区内普通 hash 链接与上一/下一镜复用场次导航的保留逻辑；独立旧入口使用同一项目助手本机保留函数。保留失败停留原对象，不重试业务命令或触发生成。成功浏览同一候选也可退出区间编辑。Ctrl/⌘ 新标签浏览保留原生行为。

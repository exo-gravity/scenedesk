# 飞书剧本正文导入（PR-4）

本片按 2026-09-16 用户明确的“团队共用文档，可统一授权给 SceneDesk”实施。正常路径为粘贴链接 → 预览 → 确认导入 → 阅读当前稿。新导入自动成为当前稿，历史为次级查阅；不增加发布、分支、合并、审批或要求用户管理版本号。后台继续保留不可变正文和固定引用。

本片堆叠于 Word 导入 PR45；尚未接入真实飞书凭据或团队文档。外部接口测试使用明确标注的合成飞书响应，业务 API、数据库权限和固定版本均走实际实现。真实应用发布、文档授权和真实导出保真度仍待团队配置后验收，不等于已通过真实飞书验收。

## 产品边界

- 接受飞书中国站租户域名的 `/docx/` 与 `/wiki/` 完整 HTTPS 链接；知识库节点必须解析成新版文档。分享参数不参与源身份。
- 通过官方导出接口获取 Word，沿用本地 Word 的安全解析和只读阅读：标题、段落、对白、基本表格与受限 PNG/JPEG。不宣称完整保留飞书嵌入数据库、画板、评论、分页、样式或任意 Office 类型。显示转换警告，并保留该次导出的完整 Word 文件。
- 不是保存外链冒充正文；预览内容来自服务器保存的导出字节。确认时不重新抓取内容，源文档随后修改不改变刚才的预览。
- 不做个人 OAuth 或通用连接器中心。没有应用配置、未绑定项目、源权限不足，均显示可执行的管理员下一步；用户仍可上传本地 Word。
- 原件在此特指“本次飞书官方导出文件”，不是飞书实时文档自身。下载和历史正文每次检查当前 SceneDesk 项目权限。

## 管理员配置

生产私有配置文件路径沿用 `SCENEDESK_CONFIG_FILE` / `/run/secrets/config.json`。在 API 配置中增加可选 `feishu` 对象，其形状见 [独立示例](../../deploy/examples/feishu.json)。应用密钥只能写入受保护的运行配置；不要写到聊天、代码仓库、浏览器、日志或截图。

1. 在团队飞书管理后台创建、发布企业自建应用，由团队管理员批准所需只读/导出权限。需要新版文档读取权限 `docx:document:readonly`；导出用 `docs:document:export` 或官方允许的 `drive:export:readonly`；知识库链接另需 `wiki:node:read`。以实际应用后台可授予范围及官方文档为准。
2. 把目标团队文档/知识库节点授权给应用。仅获得应用级权限不保证能读任意文档或其中受限制的块。
3. `feishu.tenantId` 填 SceneDesk 工作室 UUID（不是飞书租户编号）；`appId`、`appSecret` 为该团队自建应用凭据。
4. `sources` 每项明确指定 SceneDesk `projectId` 与规范 `docx`/`wiki` URL。同一文档允许多个项目使用时分别列出；未列出的项目不可借共用应用读取。UI 提示“尚未授权给当前项目”时，管理员核对文档权限，新增这一精确绑定后重启 API。配置最多 256 项，不支持通配符。
5. 本地开发可使用 `FEISHU_CONFIG_FILE=/absolute/private/feishu.json`；文件内容就是示例的独立对象，建议权限 `0600`。这一变量不接受密钥正文，也不能指定外部接口根地址。不要在已有用户演示环境中随意替换配置。

撤销项目源绑定后，新的读取和未提交预览的确认立即拒绝。已成功导入的固定正文/导出原件仍是项目内容，按项目权限可读；需要撤销既有内容访问时，应调整 SceneDesk 项目成员权限。应用密钥轮换不改变同一 appId 的源身份；切换 appId 则要求重新读取。

## 固定快照与恢复

- 读取意图先持久化为本人私有记录，再在数据库事务之外调用飞书。每次短事务重新检查会话、当前项目与归档状态；不持有项目数据库锁等待外网。
- 官方异步导出有短租约与同票据轮询。结果未知的创建不自动重复提交；用户明确重新读取时生成新身份。轮询/下载失败保留原票据，权限类失败停止。
- 单个导出原件上限 4 MB；每人每项目最多保留 5 个待处理预览。可用预览有效期 24 小时，过期接口不再返回正文。新读取会清理该用户本项目的过期及已经导入的预览；未再次访问的项目也受 5 份硬上限约束（最多 20 MB 原始导出字节，另有受限解析表示）。不声称到期时刻有独立后台物理删除任务。正式导入的原件和正文独立保存，不受预览清理影响。
- 确认绑定快照 UUID、SHA-256、原提交者、导入请求 UUID 和打开时的项目内容前置条件。先查成功回执，再检查未提交预览；正常新确认重核当前源权限及 wiki 目标身份，并保存相同字节、正文、阅读表示。
- Feishu 导出接口不提供固定源修订导出参数。因此 `observedRevision` 仅记录读取时观察到的源编号，不承诺是飞书原子版本快照。SceneDesk 自身导出的字节摘要与阅读正文是固定事实。
- 来源记录包含规范 URL、docx/wiki 类型、文档 ID、标题、观察编号、下载时间、确认时权限核对时间以及 `team_application` 授权方式。迁移 `0115` 检查必填字段，拒绝缺失/JSON null discriminator，并通过延迟约束匹配本人固定预览。
- 同一预览最多产生一条 ScriptRevision。冲突返回 412，保留输入和预览；先查只读成功回执，无保存证据后用户才能明确核对当前稿，使用新的导入身份继续。成功回执、下载与历史不依赖飞书在线状态。
- 浏览器仅存链接、请求身份、摘要与确认前置条件。离开/刷新恢复同一次读取，不存凭据。异步操作具备组件生命周期和意图校验，旧回包不得清除新草稿。保存成功与本机草稿清理一致后才收起预览。

## 安全与验证范围

网络目标固定为 `https://open.feishu.cn/open-apis`，不抓分享网页、不跟随 HTTP 重定向、不接受调用方提供的 API 根地址；每次请求超时 10 秒。JSON 响应限 512 KiB，下载按实际流量和声明大小双重限制。OOXML/ZIP 路径、DTD、外链、压缩体积与图片尺寸限制沿用 Word 导入实现。上游响应中的任意消息不直接透传给浏览器或日志。

当前代码验证项：

- 适配器：规范链接/错误域名/地址与项目隔离、wiki 类型、权限/限频、固定官方端点、禁止跳转、下载大小、敏感上游消息不回显。
- 专项数据库：预览不创建正式稿，NULL discriminator 的受限角色直接 SQL 拒绝、快照不可变、权限/绑定撤销、源更新后导入相同快照、丢响应回执、跨项目/跨用户隔离、并发 412 输入保留、未知创建不重发、容量上限、归档后只读回执。
- E2E：实际 Web/API 上传链接和读取合成官方导出，确认前未导入、刷新恢复、真实下载哈希、源权限失败、真实确认已提交后故障注入丢回包并仅用回执恢复。

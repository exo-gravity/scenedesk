# 资产固定版本与人工设定

2026-09-11。在真实身份、项目权限和[素材导入](30-media-import-service.md)之上，接通项目资产和工作室共享资产的版本工作区。全部操作使用人工输入与已验收素材，不需要模型账号。本切片不包含私有资产发布为共享、镜头中的状态／参考绑定、候选采用或编辑用片；它们仍按[实施进度](22-implementation-progress.md)继续交付。

## 可操作行为

从项目设定、集场镜或工作室导航进入资产区，按类别、状态和文字搜索分页浏览。资产分为角色、空间、道具、声音、风格；名称、检索说明和标签单独维护。创建资产身份后明确建立首个设定版本，文字版本允许暂时没有参考文件。

固定版本保留设定、按用途划分的媒体参考、并存造型以及角色的默认声音固定版。新增晚礼服不覆盖日常服；修改一项造型仅递增该项的修订数，稳定造型 ID 保留。造型引用由 `lookId` 与父资产固定修订共同定位，造型修订数不能单独充当全局内容身份。首版历史详情通过直接固定版本接口读取，浏览历史不会改当前版本。

保存设定产生新的草稿修订；项目负责人／工作室管理员另行确认某个固定版。确认历史版本不会切换当前指针，也不表示成片已经批准。管理员可直接创建共享资产；项目成员明确引入某个共享固定版，重复引入返回原记录。默认声音可从项目或共享声音中选择确切版本，共享选择先明确引入，再保存在角色的新修订里。共享声音之后产生 v2，不会升级已使用的 v1。

参考选择器只提供当前项目及共享区已验收的素材；归档停止新引用，原有固定版仍可读取。归档资产不能继续新增修订，既有记录和检索信息保留；归档项目整体只读。使用位置目前返回有权读取的直接资产版本依赖，不把未来的镜头／剪辑使用位置假装为已实现。

草稿按登录用户、范围、资产和独立标签页身份保存。刷新可恢复未提交内容；冲突核对采用原基线、本机输入和服务器版本，未修改字段保留同伴的新值。同一造型按字段核对；服务器已移除、本机仍修改的选项作为新的造型 ID 保留，避免冒充被删除选项。提交期间禁止继续改写输入；读取新当前版本时保持编辑器挂载，直到保存结果、页面版本与本机草稿清理一致。

## 数据与权限

迁移 `0009_asset_versions.sql` 建立资产、固定修订、造型身份与快照、媒体引用、固定依赖和共享引入。复合外键、行级权限、不可变约束和投影触发器共同限制引用；JSON 定义与媒体／依赖表必须一致。引用媒体须属于所指定固定资产版本；私有素材、错误角色造型及伪造投影不能穿过范围约束。定义大小、造型和参考数量都有界限。

服务接通 12 个操作：资产创建／列表／详情／元数据修改、固定版本列表／详情／新修订／确认、归档、共享引入／引入列表、使用位置查询。动态资源先读取实际归属、绑定项目权限，再检查幂等重放。修订使用资产根的 CAS，确认使用固定修订自身的 CAS。两者的 revision 含义分别保存，不能混用。

# 49 单视频生成前端切片

2026-09-11 开始，2026-09-12 完成前端验证。基于单图前端 `d05f755`，独立分支 `feat/video-generation-workspace`。本片复用固定 GenerationPlan/GenerationJob、画布来源与结果协议；没有新增视频任务类型、Take 自动创建、采用、剪辑或渲染。本文的前端验证与受控传输不能代替实际 API、worker、存储和模型验收。

## 用户路径与参数

分镜“本次创作输入”增加“生成视频”，与图片共用同一份人工提示和参考，但使用独立的固定生成计划、本机任务记录和历史。选择图片／视频不会把已有任务改成另一种目的。自由画布的生成区按明确选择的图片或视频草稿组织输入，历史仍可以读取已删除来源的固定计划。

视频能力必须为实际启用、已验证可执行能力。测试仅开放独立 `video_fixture_v1 / test_fixture` 身份，不将 `image_fixture_v1` 或 `target_profile_fixture` 作为视频执行能力。时长是能力范围内的正整数秒；尺寸与画幅来自 Capability。只有 `audioOutput=true` 才提供明确的声音选项，默认不生成声音。固定计划回显时长、声音、尺寸、模型、提示与来源；切换能力重新核对输出参数。

手工原文、固定 shotRevisionId、参考及固定 assistanceSource 一起进入新计划，建议正文不会在执行时隐式补入。画布使用已保存的文档修订、原 prepare/history/materialize 契约，不隐式添加当前镜头。执行后编辑原草稿不改变固定任务。画布正在自动保存、尚未本机保留或存在待核对写入时，准备计划和核对添加位置会禁用并提示先完成保存；最终仍由原 save/CAS 守卫核对固定版本。

## 结果、恢复与播放

- 用户明确确认计划后执行一次；未知提交、页面刷新和模式切换只读核对。恢复提交沿用原计划和幂等键。归档失败仅恢复原结果，不重新调用模型。
- 只有 succeeded 的实际 Media 才作为成功结果呈现；`reconciliation_required` 即使保留 mediaIds 也不能显示为确定成功或添加到画布。
- 独立视频结果首先展示元数据／可用海报，点击“预览视频”才读取播放授权并挂载播放器。ready proxy 优先，无可用 proxy 时可明确播放已验收的 H264/AAC 原 MP4；浏览器解码失败保留原片取回入口，不伪称预览成功。派生物失败不改变已经可用的原片和任务结果。
- 媒体访问复用现有 mediaPost，携带会话、CSRF 与幂等键，访问 URL 不进入恢复记录。主线程单图实际联调曾发现独立图片组件漏传访问幂等键，已由主线程修正；本片不覆盖该组件，并在视频受控访问验证中检查必需请求身份。
- 关闭预览、离开视口、隐藏标签页和切换工作区会释放本视频播放器；过期授权只重新读取固定素材，保留播放位置。共享 MediaPlayer 在播放、取消静音或从零提高音量时暂停其他正在有声播放的实例，静音预览可以保留；卸载清理登记、暂停并释放 source。
- “在素材中取回原片”沿用现有素材页面。画布结果先确认固定位置，再按原版本和幂等键添加独立视频节点；丢失回执不会自动重发，显式恢复不会重复节点或覆盖原草稿。候选创建和采用仍由现有明确入口单独完成。

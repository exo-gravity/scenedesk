# 镜头列表与固定选用原片交接

2026-09-16。对应[实施计划](70-creative-workspace-refactor.md) PR-6 的镜头整理部分及[验收矩阵](73-creative-workspace-e2e.md) CW-13/15。基于 PR #45 `459dc36` 并行开发，保留原候选工作台与场次入口；本片不代表 PR-6 或整体重构已完成。

## 产品边界

画布工具栏提供可选「镜头列表」：场次选择、镜头顺序、单镜预览、两份实际视频比较、明确选用、清除选用和下载已选用原片。列表保持 `Shot.sceneId`，不创建新的 Shot 父级，不将画布节点自动变成镜头，不把结果放到画布等同于选用。新增镜头复用原内容创建与恢复流程。没有场次时明确说明先建立归属，不静默补建场次。

选中画布实际视频后，可以从列表登记固定 `Take`，保留媒体、镜头要求、入出点及说明；图片仅作创作参考，不能冒充视频候选。预览其他候选不会改变当前选用。旧要求候选可继续查看，沿用仍走已有候选工作区。历史记录折叠在次级入口，不提供分支、发布或审批式版本管理。

镜头排序提交该场次完整集合，包括已归档镜头，以内容根 CAS 保护并发。归档项目／场次／镜头保持读取能力，禁止新增或选用。关闭弹层、换镜头、换场次前保留未提交输入；保留失败停留并说明。排序失败／刷新通过已有 IndexedDB 草稿明确恢复；冲突时才核对当前集合与版本。候选创建、选用仍复用既有持久化与恢复语义，没有第二套创作状态。

## API 与权限

新增 `POST /v1/tenants/{tenantId}/projects/{projectId}/shots/{shotId}/selection/download`，输入固定 `selectionId`，返回固定 Selection ID、Take、Media 和短时原件下载授权。服务端在同一受限角色事务中核验当前项目权限、镜头当前选用、固定视频媒体及存储对象版本。选用已变化返回 `409 SELECTION_CHANGED`，不会替换为新选择；无 Take 的清除记录不可下载。

这是完整原视频下载，候选区间只随结果说明，文件未裁剪。第一片未新增转码、剪辑、渲染、打包或审批；本轮批量交接增补见下文，仍不另建导出任务状态。

下载每次重新鉴权、重新核对选用并签发，不重放缓存中的签名地址。已发出的短时授权仍固定原媒体，不能变成后来选用的另一份视频；权限撤销会拒绝新的访问申请，既有对象存储授权按自身到期时间失效，不声称即时吊销。归档后的历史选用可在仍有权限时下载。`createTake` 和 `reorderContent` 新增缓存前当前归档门禁；撤权也不能通过旧幂等成功响应读取私有对象。本片没有数据库迁移。

## 本场已选用原片包（2026-09-16 增补）

镜头列表中的「下载本场已选用」先打开本场交接清单，再明确确认下载。清单固定顺序、镜头名称、候选创建时的固定镜头要求、候选说明、选用理由及整数微秒入出点；只打包未归档镜头已明确选用的完整视频，不会把当前预览／比较候选混入。没有选用时不生成空包。已归档镜头和未选用镜头分别显示省略数量；上级已归档不允许批量交接，仍可使用原有单片历史下载。

ZIP 内含 `originals/`、`shots.csv`、`manifest.json` 和 `README.txt`。CSV 为带 BOM 的 UTF-8，保护公式前缀、引号及换行；JSON 保留精确 Selection、Take、Media、固定镜头要求身份与 SHA-256。原片文件名采用服务端生成的顺序和 UUID，不把用户输入作为路径。清单不包含私有存储 key、对象版本、签名 URL 或凭据。文件未裁剪、转码或渲染，不冒充整集成片或已审阅 Delivery。

新增的两个读取接口和细节见[接口规则](06-api-contract.md)。预览的短时票据只绑定本次清单，不是持久导出任务或新的版本管理。服务端两次在现有受限项目授权事务下核验，慢文件 IO 在事务外完成；中途撤权、换选用、改顺序／说明、归档或原件失败都会拒绝发送包。使用 `MediaStore.download` 核验固定版本、长度和摘要，再由 `yazl` 顺序流式打包到隔离临时目录，完整形成 ZIP 后重新核对权限与清单。用户断连取消准备，输入流关闭后删除原件和 ZIP，释放并发槽。客户端中断保留清单，重新查看清单必须明确操作，不会让新选用自动替换已打开确认内容。

限额为每包 100 片／合计 256 MiB（单片同限），准备 180 秒、单原片读取 60 秒，完整包传输 120 秒；每用户同进程一包，每进程最多两包。页面说明按场次交接及超限后单片下载。无数据库迁移，不创建转码或制作 Worker，不运行模型。`ShotListLauncher` 新增可选 `initialShotId`／`label`，供旧镜头链接定位到列表；草稿保留及切换守卫沿用原流程。

专项验证包括原片 ZIP 解包及 SHA-256、顺序／微秒区间、CSV 安全、空选用／归档项、篡改或跨范围票据、原件失败后的同清单重试、中途换选用／排序／撤权及真实 HTTP 断连后的文件清理和并发槽释放。新增 `tests/e2e/selected-delivery.spec.ts` 两条真实 Web/API 流程；使用合成视频和隔离数据库，浏览器执行与根统一视觉验收结果在最终提交证据中记录，不将已编写脚本当通过。真实模型和团队实际镜头组验收仍分别记账。

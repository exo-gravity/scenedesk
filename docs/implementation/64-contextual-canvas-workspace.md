# 场次画布的局部编辑与固定对象助手

2026-09-14。状态：实施与整合验证中，尚未合入。用户已确认[画布重设计 v0.5](../design/canvas-redesign-v0.5-2026-09-14.md)；本片取代公共底部编辑面板，保留场次自由探索、固定输入、明确执行与恢复。

## 行为边界

- 场次路径、模式、保存、任务与助手进入同一顶部栏。普通辅助区覆盖画布，展开不改变 React Flow 容器和视口。各辅助区保留输入，关闭保留用户最新导航。
- 选中对象与编辑目标分开。媒体查看、文字编辑、草稿准备各有明确入口；未完成草稿不能假装已生成的来源。切换编辑先耐久保留本机草稿，保留失败时停留原对象。
- 近节点输入独立于节点尺寸和世界坐标；空间不足或目标离屏显示有名称的提示。复杂输入可进入同一编辑会话的专注视图，退出不产生新草稿或新任务。
- 新草稿与固定尝试分开保存。历史浏览使用独立恢复分区，不覆盖同一节点的当前生成输入。节点只显示真实最近尝试状态，旧成功不等于新草稿已经完成。
- 画布助手明确接收所选节点，允许零镜头。固定节点版本、内容快照、媒体及资产版本不会自动升级；不隐式遍历整张画布或所有连线。新建议应用先展示准确目标、基线和正文差异，明确确认后通过 CAS 写回；冲突与未知回执保留原意图。

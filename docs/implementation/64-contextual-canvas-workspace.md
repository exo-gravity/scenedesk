# 场次画布的局部编辑与固定对象助手

2026-09-14。实现与本机整合验收已完成，最终合入状态以 [PR #35](https://github.com/exo-gravity/scenedesk/pull/35) 为准。用户确认的[画布重设计 v0.5](../design/canvas-redesign-v0.5-2026-09-14.md)取代公共底部编辑面板；同日最新纠正进一步确定 AI 助手为贴右满高的布局侧栏及真实对话流程，取代此前助手覆盖层。

产品默认只展示英文品牌 `SceneDesk`，按用户最新纠正保留精确大小写。导航、默认入口及业务页面标题统一使用该名称，业务文案继续使用中文，历史设计记录不改写。

## 行为边界

- 场次路径、模式、保存、任务与助手进入同一顶部栏。普通辅助区覆盖画布；AI 助手使用贴右满高的布局侧栏。打开助手分配布局宽度，但不自动适应内容或改变已保存的平移、缩放和选中对象。各辅助区保留输入，关闭保留用户最新导航。
- 选中对象与编辑目标分开。媒体查看、文字编辑、草稿准备各有明确入口；未完成草稿不能假装已生成的来源。切换编辑先耐久保留本机草稿，保留失败时停留原对象。
- 近节点输入独立于节点尺寸和世界坐标；空间不足或目标离屏显示有名称的提示。复杂输入可进入同一编辑会话的专注视图，退出不产生新草稿或新任务。
- 新草稿与固定尝试分开保存。历史浏览使用独立恢复分区，不覆盖同一节点的当前生成输入。节点只显示真实最近尝试状态，旧成功不等于新草稿已经完成。
- 画布助手明确接收所选节点，允许零镜头。固定节点版本、内容快照、媒体及资产版本不会自动升级；不隐式遍历整张画布或所有连线。新建议应用先展示准确目标、基线和正文差异，明确确认后通过 CAS 写回；冲突与未知回执保留原意图。

## 对话与结果处理

用户消息形成固定计划；发送先核对，执行和写回均明确确认。真实保存的建议出现在对话流，下一条输入独立保留。继续讨论明确引用上一份建议的确切 artifact/revision、原正文和原指令；当前附件单独核对，不自动升级历史输入。零镜头的画布来源由服务端真实校验，追加 0101／0102 迁移与受限角色授权。

首次确定拒绝保留耐久回执后允许明确返回编辑；未知提交始终保留原请求身份；结果放置的未知重送即使收到 412，也不会被改成可重新选点的冲突。刷新重新核对当前权限并恢复真实消息、结果及未发送输入。建议应用通过目标版本 CAS，只修改所选草稿的提示词。

生成结果首次核对落点时，为整组结果寻找避开已有节点的位置；已确认及未知的放置意图保持原样。默认水平放置值与服务端共用 320 宽／340 步长，边界无完整空隙则明确保留任务并提示整理画布。

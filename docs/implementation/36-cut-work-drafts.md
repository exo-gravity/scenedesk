# 共享剪辑工作稿：实施中

2026-09-11。依据 E05A、PR-12、[21 技术定案](21-technical-baseline-closure.md)的工作稿与有限恢复历史。完整 MVP 及本切片均尚未完成；当前功能分支为 `feat/cut-work-drafts`，尚未推送或合并。

## 已实现的服务与约束

Cut 建立空主视频轨，使用项目输出规格；场次剪辑从场次当前父级解析集，不存两个可能随场次移动而矛盾的父级。列表支持场次／集筛选。当前 Cut 内容保持只读，待 E05 接入明确归一确认后才开放更新。

共享工作稿有独立修订号。无记录时 GET 返回虚拟 revision 0，不创建记录；PUT 使用工作稿自己的 If-Match，追加不可改写的修订。相同正文及基线的重复保存不增加修订。空轨、空字幕、零时长、越界放置和待处理事项可以保存，服务端重新计算问题；反向区间、重复身份、伪造类型与无权来源拒绝。声音、对白固定要求与声音资产通过类型化外键关联，允许缺少片段的未完成对白关联，不能编造对白来源。

正文按 `editing-json-v1` 编码：Unicode 码点排序对象键、数组保序、字符串不归一化、ECMAScript 数字表示、UTF-8 SHA-256。保存确切 canonical 字符串和可查询 JSONB；两者均可使用 TOAST，容量依据未压缩 canonical 字节。旧命令及创作依据的哈希实现没有改变。

同 Cut 的正文按哈希去重；媒体、候选、采用记录、对白、声音版本和输出规格质量参考均有真实外键保留。已归档媒体只允许保留当前工作稿中同一个实际来源槽位；取回旧历史仍是一次新写入，不能借历史去重绕过归档规则。候选范围之外的片段保留为明确问题，不能被当作已经通过归一。

保存遵循项目、Cut、工作稿、引用的锁顺序，正文、历史、引用、根版本和审计同事务提交。采用影响列表现在查询实际工作稿中的镜头候选引用；改变或清除采用不会重写这些片段，也不改变 Cut。

每次写入执行有限历史保留：当前与前一版、最近 24 小时最多 100 份、7 天内每 15 分钟最后一份和 30 天内每天最后一份。去重后的普通历史正文预算 256 MiB，先淘汰普通近期修订，再淘汰检查点；当前／前一版不淘汰。读取历史按修订倒序、对象绑定游标分页；已过期版本为 410，未出现的版本为 404。纯读取不会创建或修改内容。数据库保护当前及前一版，并禁止覆盖正文或回退工作稿指针。

新增迁移 0012–0014 均在独立测试 schema 中执行。0013 修正 BEFORE INSERT 与 upsert 的交互并补齐规格媒体引用，0014 修正触发器 OLD 记录与 SQL 别名冲突；已执行迁移不回写。日常开发数据库随后通过 `upgrade:business` 应用三项迁移并重新核验运行角色权限，API 已重启使用当前工作稿服务。

## 当前验证

`npm run check` 通过：类型、UI 规则、生产构建及 31 项单元测试。`npm run test:db` 的 91 项全部通过，其中新增工作稿 12 项覆盖虚拟版本、真实 CAS、正文去重、归档槽位、范围隔离、采用影响、对白与声音来源、质量参考、容量限制、104 次实际编辑后的回收与受限角色保护。逐项重放测试验证同伴未选片段、新条目及顺序不被覆盖，轨道增删不能隐式丢弃其余片段。对白测试进一步覆盖精确半开区间、片段／整轨静音、同片段多标注及 1500 路重叠，不枚举平方数量的声源组合。

内容指纹使用固定标量／数值夹具，Node 输出与 Python 对相同 UTF-8 输入的字节数及 SHA-256 一致；没有把 Python 默认浮点序列化当成 ECMAScript 编码。微秒诊断使用整数运算，验证两个安全整数相加越过浮点精度边界时仍能发现一微秒越界。

`npm run test:media` 的 25 项全部通过。数据库测试中的媒体是关系夹具，文件验收依据独立媒体套件；这些结果不代表真人剪辑验收。

独立的本机恢复存储已实现 7 天／20 份、元数据字节计量、按用户／项目／对象／标签页分区以及事务性写入与清理。每次写入使用新的本机 token 防止旧回执清除重新建立的副本；超过上限拒绝新副本，不自动删未同步工作。真实 IndexedDB 的竞争写入、写／删事务中断、迟到清理、过期、刷新和分区清除通过，见[组件与页面验证记录](../../output/playwright/editing-work/README.md)。

浏览器恢复校验与 API 复用无文件系统依赖的 Ajv 编译器；浏览器从同源公开契约读取 Schema，仍须先取得实际对象访问权，Schema 校验不提供授权。没有在前端另写一套字段规则；浏览器对合法工作稿、额外字段及不修改输入的验证已通过。

## 已接入的页面与保存过程

场次内可在镜头制作与剪辑间切换、建立空白剪辑，并明确从候选、项目／共享视频、音频或内嵌声音加入片段。片段设置使用确切十进制秒转换微秒；视频原声静音、增益、画面适配、字幕文字与时间、整轨静音／隐藏、字幕烧录选择进入工作稿。页面显示源素材预览，明确当前尚无混音／字幕烧录／整场渲染结果。持续片段设置占右侧工具区，主区保留媒体，轨道条位于其下；已检查 1366×900 与 320×740 生产构建。

独立保存控制器持有本机基线、当前修改、未完成数字输入和固定在途请求。静默 800ms／持续输入最长 5 秒串行保存，输入法组字及无效数字暂停自动保存。请求必须先落入本机事务；回包更新基线而保留后续输入。未知结果先读当前修订、基线、正文及指纹，再确定成功、同版重送或冲突；已成功后的本机清理失败仅重试清理。导航离开后的回执仍由控制器处理，返回先核验当前访问；退出登录与检测到撤权时停止控制器并清理缓存，跨标签页即时通知及完整生命周期验收尚待补齐。

冲突界面显示共同基线、本机和已查看的服务器版本，仅将明确勾选的本机操作重放到该服务器版本。新增片段、轨道和顺序分别核对；未选同伴变化保留，非法悬空轨道关系拒绝。比较期间再次变化要求重新比较，控制器保留手动合并内容。历史入口按实际游标分页读取保留版本，取回作为新的本机修改，仍走引用校验与保存 CAS。确认绑定所选固定历史、本机正文／原始输入、工作稿及 Cut 版本；相同内容的轮询不使确认失效，实际变化必须重新核对。分页读取与资产使用同一个函数，并与单次读取分开缓存，避免数据结构相互污染。

保存控制器的 9 组真实浏览器／IndexedDB 故障验证通过，包括授权前不展示恢复、本机读取完成前不开放编辑、在途新输入、离开后回执、丢包核对、同一请求重试、二次冲突、本机写入与提交后清理中断、撤权后迟到回复、输入法与节流。此层使用可控传输；实际页面另通过真实 API 验证 r0 只读、视频与字幕保存、无效原始输入刷新恢复、源视频解码，以及实际 412 后逐项重放保留同伴独立声音／字幕变化。页面工作稿 r3 时 Cut 仍为 r1，没有通过工作稿保存隐式生成固定稿。

对白面板可给视频原生混合声音、独立音频及字幕建立关联，明确选择镜头要求固定版、该版本内的台词、可选源区间及声音固定版。按固定修订 ID 回查原始要求，当前镜头的新文本不会替换旧引用。声音选择器允许明确引入共享历史版；台词要求中的声音必须点击沿用后才进入关联。

独立对白与时间上重叠的原声逐项选择整轨静音或保留当前设置；保留不会把已静音片段重新打开。尚未决定可明确保存关联及待核对事项。服务端将同一固定台词的实际重叠、未静音声源列为独立诊断；未知音频内容仍须回放。由固定台词整理字幕只生成文字草稿并保留回放核对事项，人工完成事项不清除自动诊断。

关联表单的所有未应用输入进入本机恢复，导航改变所选片段不会静默改换表单目标；目标片段、关联或原声上下文变化时要求重新核对，继续保留已选台词和声音。恢复入口列出尚未应用的关联表单。移除关联、完成待处理事项的确认绑定所看到的记录内容，保留其余片段和独立事项。

声音资产详情返回当前工作稿的直接使用位置并跳回对应场次、剪辑和对白工具。数据库测试已验证：声音从当前稿移除后，保留历史仍有外键，但不再显示为当前使用。冲突比较补充完整片段增益、画面适配、候选／采用、固定台词／声音版本、区间和待处理记录。

生产浏览器新增对白全流程通过：最终技术工作稿 r8，原声、内嵌音频及字幕三类关联保存；未完成表单刷新恢复、镜头及共享声音固定旧版、实际重复声源诊断、明确静音、字幕微秒时长、人工事项与自动诊断独立、资产使用位置跳转及视频解码均取得证据。宽／窄屏无横向溢出、页面异常为 0，截图已人工查看。文档检查通过（148 操作、114 路径、222 Schema、157 样例）；见上述验证记录，仍不是完整剪辑及真实用户验收。

历史取回的生产浏览器验证已通过：34 个实际版本跨页读取，旧确认不覆盖后续本机编辑，相同内容刷新保留确认；取回 r1 追加新版本而保留原历史及 Cut r1。服务器提交后丢失回包，客户端核对 r37 且不重复 PUT；取回与同伴写入相撞得到真实 412，逐项重放历史字幕保留同伴 -6 dB 增益，最终 r39 刷新不变。共享分页提取后对白与资产流程重新通过，完整工程检查仍为 31 项单元及类型／构建通过。

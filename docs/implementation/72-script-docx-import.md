# 本地 Word 剧本导入与阅读

2026-09-16。对应 [重构计划](70-creative-workspace-refactor.md) PR-3；仍为独立 Web。本文记录实际实现边界，不把 fixture 验证视为团队实际文档验收。

## 可用行为

- 剧本默认进入阅读页：当前来源文件、导入时间、固定版本、历史切换、原件下载。原纯文本编辑保留在明确的次级入口；编辑导入文本会创建纯文本新版本，旧 Word 原件与版式不被替换。
- 选择本地 `.docx` 后，先把文件、稳定导入身份和目标内容版本保留到既有按用户／项目／标签页隔离的 IndexedDB 草稿，再请求服务端解析。预览不建立正式剧本版本；确认后才创建不可变 `ScriptRevision`。
- 导入确认带 `ContentTree.revision`。并发更改返回 412，文件和预览仍保留。丢回包或刷新后，可用只读导入回执查询核对本人请求、原件 digest、文件名和原目标版本；有保存证据才完成本地清理。无回执时，用户核对新基线后以新 `importRequestId` 明确继续。
- 导入、原件和项目当前剧本指针在同一事务中保存。稳定导入身份不受通用 HTTP 幂等缓存过期影响；恢复返回原固定版本，不再创建新版本。每次下载、固定阅读、回执和重试先验证当前项目权限。归档项目保留只读，不能新导入。
- 固定阅读接口返回规范 `text` 与结构表示；既有镜头引用继续绑定 `scriptRevisionId`、Unicode codepoint 范围和原文。选文进入项目画布尚待 PR-2／连续创作整合，本片不声明该跨页面动作已完成。

## 文件与显示边界

首版只承诺 `.docx`，不等同支持所有 Office 格式。原件 ≤4 MB，ZIP ≤500 条目，实际流式解压累计 ≤20 MB，正文 XML ≤8 MB／10 万节点／64 层，规范正文 ≤50 万 codepoints／1 万块。不读取系统文件或外部关系，不执行宏、DTD、脚本或文档链接；加密、宏、损坏包及不支持结构会拒绝或明确警告。

阅读表示保留标准 Word 标题、段落、对白、普通表格文字。PNG/JPEG 支持内嵌，单图 ≤1 MB、总计 ≤3 MB、边长 ≤8192、≤1600 万像素；PNG 检查分块完整性与 CRC，拒绝动画，JPEG 检查尺寸标记。超限、损坏或不支持图片以占位提示保留位置和原件。它不是媒体生产归档，也不把导入图片冒充项目资产。

字体、分页、自动编号、合并单元格、嵌套表格、表格内图片、旧式图形、嵌入对象、公式、页眉页脚、批注与脚注不承诺完整复原，界面给出对应说明，原件始终保留。修订标记按接受修改后的正文阅读，外链只保留文字。必要图片及特殊模板须用团队实际样本补充验收；不以合成小图片声明真实画册或任意 Word 模板兼容。

## 数据与接口

迁移 `0110_script_docx.sql` 增加固定来源信息、结构表示、请求身份及独立 `script_originals`。Word 原件采用有上限的私有 PostgreSQL bytea；项目 RLS、不可变触发器及延迟约束保证原件和来源 digest 对应。使用显式运行角色授权。此取舍避免给文本 Word MVP 新增存储部署；未来迁入私有对象存储时仍维持相同 `ScriptRevision` 身份及授权下载协议。

- `POST .../scripts/preview-docx`：原件解析预览，服务器不信任客户端解析表示。
- `POST .../scripts/import-docx`：原件、预览 digest、导入请求 UUID 与内容 CAS，重新解析后保存。
- `GET .../scripts/{revisionId}`：固定正文、来源与阅读表示。
- `GET .../scripts/{revisionId}/original`：鉴权后获取原件内容；无公开地址。
- `GET .../script-imports/{requestId}`：只读查本人保存回执与原基线。

历史列表保留原规范文本及来源元数据；图片阅读表示按所选固定版本获取，避免一次历史列表返回所有图片。未改造图／视频上传允许列表。适用协议同步在 [领域模型](03-domain-data-model.md) 和 [API 规则](06-api-contract.md)。

编号 0106–0109 为并行项目画布切片保留。当前迁移 runner 允许空档但拒绝后补低号迁移，因此本片只有独立测试 schema 可先应用，合入和共享环境升级必须排在项目画布已使用迁移之后；不添加空占位迁移。

独立 PostgreSQL schema 的 API 集成覆盖预览无正式修订、并发重复确认、固定阅读／原件、内容冲突、digest 错配、跨项目、协作者读取／撤权、归档、原件不可变、HTTP 回执清除后领域回执恢复。本片没有付费模型调用。

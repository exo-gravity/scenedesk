# 创作体验升级：视觉、信息结构与画布交互

2026-09-13—14。用户要求在现有视觉方案上进一步提升作品展示、信息组织与操作体验，并以真实端到端测试验收。实施前已拉取 GitHub 最新 `main`，确认基线为 `585eb10df26bc7b1d32d8b67bb99a8ee7b596898`；不是在旧浏览器标签挂载的代码上继续改版。[综合设计决定](../design/creative-experience-refinement-2026-09-13.md)整合了信息结构、画布交互及独立验收三个视角的审查。

## 最终行为

- 共同视觉：收紧全局导航占用，统一中性表面、标题尺度与留白；图库突出真实作品，低频管理移入菜单。场次封面读取实际采用候选，不根据任意素材推断制作状态。
- 剧本与设定：已保存剧本默认阅读，明确进入编辑、阅读预览和历史查阅；提案助手按需展开。故事设定和正文在同一创作页，页签与 URL 同步，切换保持输入；项目设置提供直达入口。保存仍追加版本，恢复输入和冲突提示保留。
- 资产与素材：使用固定版本的真实参考预览，分类与搜索更紧凑；详情先看内容和参考，编辑按段展开。图库按可见区域读取，未建立首版、无图、归档和不可读状态有实际说明。导入面板显隐保持任务及文件状态。
- 画布与镜头：选中对象旁出现带对象名称的操作条；双击空白处先选择内容类型，空画布可直接写想法、导入参考或开始创作。参考材料、节点属性和高级参数按需展开，创作输入面板有界；图片、视频、声音切换保持各自输入。正常保存状态精简，失败与冲突仍有可操作入口。

保持 Mantine、Phosphor、React Flow 和 CSS Modules 的现有组件体系；没有新增 UI 依赖。改版没有改变固定输入、明确执行、候选选择与采用的区别，也没有重新引入后期剪辑、计费或运营范围。

## 实际复核与修正

生产页面检查与交叉代码审查发现并修复了以下问题：空剧本在输入首字时不能因预览状态切走编辑器；固定生成计划摘要需显示已确定的画幅和随机种子；菜单文件选择器等待操作系统回调时不能提前卸载；同页切换故事设定需要跟随 URL；所选节点在视口外时，浮动工具条必须标明实际对象，并按自身高度保持在可操作范围内。

端到端上传测试另发现选择模式的空白双击未打开菜单：React Flow 将选择模式的 pointer-up 传给 `onPaneClick`，其 `detail` 不是双击次数。改为在真正的双击事件中验证目标为空白 pane 后打开菜单，节点内编辑与只读限制保持原行为。

本机完整 `npm run check` 通过，包括合同生成一致性、UI 规则、类型检查、生产构建和 144 项测试。上述末次双击修正后再次生产构建和 UI 检查通过。浏览器证据使用隔离 PostgreSQL、MinIO、真实上传处理和实际生产构建；保留演示项目不承担故障注入或清理。

已验证的真实流程包括：剧本阅读／编辑／预览保持输入、刷新后明确恢复并唯一新增版本；故事设定阅读／编辑／恢复／保存；资产分类、搜索、归档筛选、固定 v1 历史与角色造型浏览、新修订恢复后唯一保存；实际视频播放时间推进；画布文字保存和刷新读回；另一会话先改后产生实际 412，明确重新应用后同时保留双方修改；素材导入选文件后收起重开、上传中收起不取消、实际处理为 ready 后校验原 SHA-256 与字节数，刷新可查原导入记录。

视觉复核覆盖 1440、1366 和 390px、深浅色与键盘操作。固定尺寸的隔离夹具截图和真实演示项目只读补充图分别保存；不把不同尺寸、不同数据的画面当作精确前后对照。独立审查与主任务实际查看 PNG 后，未发现必须修改的剩余布局问题。

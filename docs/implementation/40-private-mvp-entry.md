# 私有创作工作台的首发入口

日期：2026-09-11。依据：[38 当前 MVP 范围](38-first-release-scope-review.md)。本切片收窄实际应用入口，不改变画布与 AI 的既定能力范围，也不代表整个 MVP 或真实部署已经完成。

## 实施边界

- 正常构建进入真实业务工作台。已登录且只有一个可访问工作室时直接显示项目列表；多个工作室仍可选择。没有开通访问时显示说明、刷新访问和退出路径，不再要求创建工作室。
- 项目列表和新建项目完成后直接进入剧本与集场镜。创建者作为项目负责人，项目规格仍保留。项目设定、剧目设定、创作依据、项目／共享素材与资产保持可访问，集场镜新增明确返回全部项目的路径。搜索无匹配时可清空重试。
- 首发导航和日常页面移除新建工作室、完整成员管理、成员交接／添加、分工任务与设计演示入口。项目设置只保留创作需要的设定和归档／恢复。已有私有邀请链接仍可接受，用于已授权的试用接入；没有开放注册或新建邀请入口。
- 旧的运营、成员管理、后期和未知项目子页面地址显示“此入口暂未开放”，提供返回项目或剧本与集场镜的路径。后期、团队、任务的底层模块、接口、约束和已有数据保留。隐藏入口不是权限措施；服务端的当前身份、项目授权、幂等重试及跨项目访问隔离继续执行。
- 生产入口根据实际健康响应显示本地测试身份、未连接真实模型的状态，并保留“导入素材可用”的说明。导入素材和模拟模型不计为真实 AI 验收。
- 原型源文件和历史设计地址保留。普通构建不加载原型；仅显式设置 `VITE_ENABLE_DESIGN_PREVIEWS=true` 的评审构建可以访问旧设计页面。该开关是 Vite 构建配置，不能作为生产权限开关；发布构建应保持默认关闭。
- 归档／恢复确认固定打开时的项目对象及版本。打开后发生并发修改，服务器按旧版本拒绝，弹窗保留原确认对象；关闭并重新打开后再核对。

## 验证与剩余边界

本切片使用独立 worktree、依赖安装与 4317 生产预览，连接已有本地业务 API。当前验证记录见[入口浏览器验证](../../output/playwright/2026-09-11-private-mvp-entry/verification.md)。本地身份和新增项目均为测试夹具，不代表真实用户验收。

`npm run check` 已通过契约同步、UI 规则、类型、生产构建及 48 项单元检查（0 失败、取消、跳过）。未修改 API、SQL、存储、模型执行或媒体解码，未把未运行的数据库／媒体验证记为本切片新增证据。远端推送、CI 和合并由主实施任务在集成后验证并记录。

原定画布／AI 剩余功能、真实模型、真实登录配置、部署与干净浏览器上线复验仍按 [22 实施进度](22-implementation-progress.md) 和 [38 当前 MVP](38-first-release-scope-review.md) 继续。本次入口调整不缩减它们，也不恢复后期或商业运营为首发依赖。

## 行为与边界

项目左侧「画布」直接进入项目画布。尚未创建时提供明确创建操作，零集零场项目也可开始。创建后复用当前完整画布编辑、生成草稿、固定计划／任务与结果、历史、素材导入、助手和本机恢复；项目模式不挂载分镜台或场次助手，不要求虚构场次。已有场次通过「已有场次画布」入口继续访问；项目画布整理为场次镜头的专门操作属于后续 PR-6。

迁移 `0106_project_canvas_workspace.sql` 新建唯一项目关系、个人项目偏好，禁止 Canvas 同时作为项目和场次根，保留全部旧画布和固定输入身份。一般 Canvas API、文档修订和节点 identity 不变。助手讨论的固定 scope 在项目画布使用 `{canvasId, projectId}`，旧场次 scope 保持 `{canvasId, sceneId}`；SQL 投影、快照与执行前检查同步支持二者。

项目页侧栏、菜单中的同窗链接、已有场次入口先保留画布输入和生成草稿、助手输入，再 flush 私人偏好；失败不离开，显示可重试错误。Ctrl/Cmd 等新标签手势保持浏览器默认行为，不触发当前页退出；注销继续既有全局会话屏障。偏好仍只属于本人，其保存允许已归档项目中的浏览位置；新画布、画布正文和新生成仍不能修改已归档项目。

# 主画布与自由讨论

## 用户确认与行为

依据[已确认的主创作区设计](../design/primary-canvas-approved-2026-09-14.md)：
默认进入自由画布、完整保留分镜模式；桌面顶部居中切换模式，左侧以一体控件
搜索和切换集／场次。节点输入随世界坐标缩放，专注编辑沿用同一会话。
右侧贴边对话侧栏为两种模式共用，失败文件记录收进任务面板。

用户随后明确要求无需选择画布内容即可对话。因此新会话默认自由讨论，
文字可直接发送，节点附件可选；不要求媒体生成目标。准备生成提示仍可明确
选用，旧草稿用途和原固定任务保留。讨论正文不能直接当作媒体生成指令应用。

## 持久化与恢复

- `discuss` 使用真实计划／作业／受限 worker／不可变回复协议。发送消息固定
  当前输入后执行该条回复；未知回执沿原身份读取恢复，不自动重复执行。
- 独立画布 scope 提供权限与历史归属，不把“属于画布”当作读取整张画布的授权。
  请求只包含用户文本、显式附件及固定的历史回复链。
- 后端按固定来源解析最多 20 个旧回合，保留每轮原问题、回复及工件版本。
  总输入不超过 100000 UTF-8 字节，超限明确拒绝，不默默截断。
- 追加迁移 0103–0105，分别约束讨论归属、媒体提示边界和完整固定历史；
  已应用迁移不改写，运行角色重新明确授权。
- 模式切换保留已访问页面，隐藏播放器暂停。跨场次导航等待本机草稿与视图
  保存；本次修正了 JSONB 字段顺序导致的假 dirty 状态。

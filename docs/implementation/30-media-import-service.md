# 素材导入业务与恢复服务

2026-09-11。E03 已接通数据库、业务 API、队列、私有对象存储和独立处理进程。此记录覆盖服务端导入链路；浏览器素材工作区、资产固定版本、发布共享和候选采用继续交付，完整 E03 尚未完成。

## 已实现行为

9 个现有协议操作已实现：创建／查询／完成上传，素材列表／详情／元数据修改／归档，明确变体访问，派生恢复。项目范围按真实项目成员授权；共享范围由工作室 owner/admin 写、工作室成员读。共享读者查询上传状态不会取得上传表单；所有签发在幂等重放前重新校验当前范围和资格。已签发的对象 URL 仍有最长 5 分钟有效期，撤权阻止新的签发，不声称即时撤销已有签名。

浏览器凭证只允许写精确 staging 对象。完成确认须匹配原声明；业务媒体根与队列提示在同一 PostgreSQL 事务创建。处理器先固定 staging VersionId，再下载、限流、校验摘要、严格解码，复制到服务端独占对象，最后以实际业务根的 revision／step／epoch 验收。固定后网络中断仍重用同一版本，不因旧上传地址被覆盖而换输入。

原文件验收与预览分别提交。图片产生海报，视频产生海报和代理，音频产生代理，文档只保留原始文件。派生失败不会改变原文件的摘要或状态；恢复沿用同一派生记录、增加步骤版本。访问必须明确 original／poster／proxy，未就绪派生返回明确问题，不能静默回退。文本与 SRT 强制 attachment。实际尺寸、时长、有理帧率和可取得的时间证据来自探测；缺少 start PTS 时不伪造完整 timing。

元数据修改采用 If-Match，不能改变已验收字节、原名、来源及范围。来源证据使用有类型的外键，校验同项目或共享范围；归档证据只允许保留已有引用。归档保留字节，已有授权访问仍可下载；项目归档后也可读取，禁止业务修改。

UploadIntent／Media／MediaDerivative 增加可选 `issue`，包含公开错误代码、说明和是否可以恢复。不能恢复的摘要／类型／解码错误成为 rejected；暂时性存储或处理服务错误有限自动重试，最多 6 次，之后需要显式恢复。原片固定版本实际丢失须重新导入。客户端显示 `expiresAt`；访问 URL 到期须发起新的签发请求，不能把 24 小时幂等响应缓存当作 24 小时有效 URL。

## 权限和运行边界

迁移 `0008_media_import.sql` 建立上传、媒体、派生及来源证据表。数据库触发器保护身份、不可变字节、固定输入及终态。API 不能更新原文件存储身份或摘要；Worker 不能改人工名称、标签和来源说明。

API、业务处理器、队列调度器为不同受限登录。业务 Worker 启动时校验已登记身份；`resolve_media_work` 从数据库的真实根解析租户／项目，锁定活动范围和步骤，设置仅限该次事务的媒体上下文。伪造队列 tenant 字段无效，队列仅接受 kind／businessId／stepRevision／epoch 四个字段。没有上下文的 Worker 查询返回空；调度器无法直接读取业务媒体。

独立进程每 60 秒扫描可恢复的业务状态，通过 `scan_media_work` 只取得步骤提示并与重新入队同事务提交。上传等待超过 2 分钟、处理中超过 15 分钟和过期意图可被重新调度；不自建第二套租约。重复或过时提示由业务状态和 CAS 仲裁。原文件和派生均允许物理尝试遗留未发布对象，当前不提供自动删除权限；受控保留／清理和容量验收仍待实施。

当前本机进程可以启动受限 FFmpeg 子容器；解码容器无网络、无凭据、没有 Docker socket。持有 Docker 控制权的父进程仍属于本机可信计算边界，不能把这一点写成生产主机隔离已经验收。生产调度、存储和密钥管理须另行部署验证。

## 本地运行

先完成现有 `setup:business`、`setup:queue`；已有配置直接复用。

```sh
npm run test:media:prepare
npm run upgrade:business
npm run setup:media
npm run dev:business
```

另一个终端：

```sh
npm run dev:media-worker
```

`setup:media` 创建仅绑定 `127.0.0.1:55440` 的持久存储容器，启用 bucket versioning 和本地 UI 的明确 CORS 来源。存储镜像是冻结的本地兼容服务器；[MinIO 已归档](https://github.com/minio/minio)，不是生产选型。[固定版本的 CORS 配置定义](https://github.com/minio/minio/blob/RELEASE.2025-07-23T15-54-02Z/internal/config/api/api.go)。

初始化状态保存在被 Git 忽略且权限为 0600 的 `.runtime/media-local.json`，重跑复用相同资源。API 只加载 `.env.business` 与 `.env.media-api`；Worker 只加载 `.env.media-worker` 与 `.env.queue`，若发现迁移／API／身份密钥则拒绝启动。已有不一致配置不会被覆盖。保留本地 manifest 和 Docker 数据卷以便恢复，不把运行凭据提交仓库。

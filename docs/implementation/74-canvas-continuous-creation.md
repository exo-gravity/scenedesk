# 固定剧本选文与连续画布创作

本片基于 Word 导入与项目画布，交付 PR-5 的第一条主路径。用户从当前稿或历史稿选择一段原文，添加到项目画布；选中文字继续创建图片、视频或声音草稿。画布的生成动作组合已有保存、固定计划与执行命令，正常路径不再要求先打开内部计划再确认执行。

## 固定来源与恢复

- 复用 `ScriptExcerpt`（固定剧本修订、Unicode 码点范围、原文）；UI 不要求填写修订或范围。Word 的段落、表格与 emoji 使用保存后的规范正文选文。
- `CanvasTextContent.sourceExcerpt` 可选；有引用的原文不可原地改写。节点标题、位置可调整，用户在相连创作草稿中写新的生成描述。
- 仅新增迁移 `0111_canvas_script_excerpts.sql`：扩展永久 `canvas_node_index`，不新增业务聚合。SQL 依据同项目固定剧本验证范围与原文，节点删除后仍保留引用身份；复用原标识不能去掉或改指引用。
- 添加选文使用现有画布修订 CAS，服务器只追加这一节点。客户端在提交前保留原文与节点身份；回包丢失后读取原节点回执。相同请求不重复追加，原节点已经被移除时不自动恢复。导入新稿不升级旧引用。
- 当前权限及活动项目门禁在幂等缓存之前执行；固定回执读取仍允许归档项目历史查阅。接口重放读取当前节点状态，避免缓存旧的“仍在画布”状态。

## 生成与下一稿

`AssistantSession.generateFrom` 在一次明确点击内依次保留同一草稿请求、保存画布、固定计划与提交执行（具体前两者顺序由现有画布 resolve 回调执行）。执行请求仍先持久化再发送。画布保存/CAS 失败或期间内容改变时，不继续准备或执行。恢复页面仅读取；用户明确继续时才恢复原计划请求或原执行身份。

已有回执且处于排队、模型已接收、正在生成或归档阶段的任务可放入既有历史，继续编辑下一稿。原任务、旧计划与结果仍独立；结果进入画布仍需明确操作，新增结果节点不替换草稿，不自动采用镜头候选。提交未知、丢回包尚未核对以及需要对账的状态不能通过“下一稿”放弃原提交。

节点编辑器按视口限制高度并滚动内容；空间不足时保留可见“专注编辑”入口。专注模式沿用原有编辑树和保留屏障。

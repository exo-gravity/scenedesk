# 编辑器提交后的本地恢复

本切片处理服务器明确返回成功之后的本地收尾，以及提案单项编辑在本地草稿之间的转移。源码中的统一草稿模块承担存储排队、提交回执、清理重试和恢复状态；业务页面提供成功后的导航动作。

## 已保存内容与本地清理

成功回调属于业务命令本身，先于缓存刷新执行，编辑器卸载不会取消它。服务器保存成功后先停止原草稿写入，为当前用户、对象和标签页保存小型提交回执，再等待原存储队列完成并删除草稿。成功提示和导航只有在清理完成后继续。IndexedDB 删除事务失败时，页面明确显示服务器已保存，提供单独清理重试；旧编辑表单收起，避免再次提交同一业务内容。

回执由 sessionStorage 独立保存，不含输入正文、响应正文或身份凭据。刷新后若发现回执，先清理对应草稿，不提供恢复已提交输入的入口。回执只在草稿删除成功后移除。此行为继承现有独立标签页身份；复制标签页取得新身份，不接管原标签页草稿。

该收尾统一用于集场镜、剧本、剧目与样片、资产创建与修订、素材元数据、任务、CSV 导入、提案保存／采纳和创作确认。用户主动放弃未提交草稿时，也等待删除成功才移除恢复入口，失败仍保留草稿。

## 提案单项转移

“保留本项修改”先将完整更新写入本地提案草稿，确认写入成功后才清理单项草稿。父草稿写入失败时，单项输入和错误仍在原处；子草稿清理失败时，明确显示已保留到本地提案、尚未提交服务器。清理重试不再次转移或提交内容。用户仍须保存提案修订，再明确采纳。

取消单项修改仅清理本地草稿，不产生服务器提交回执。CSV 已选择的追加场次不可用时，保留 CSV 和原意图，要求明确重新选择目标。内容使用位置的链接找不到场次、镜头或固定要求时，显示具体提示；移除定位参数会关闭该链接打开的历史。

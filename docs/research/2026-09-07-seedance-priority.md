# Seedance 优先接入核查

核查日期：2026-09-07。仅查官方发布与 API 文档；未登录供应商账号、未购买、未执行生成或质量测试。以下“官方声明”“API 文档列明”“本账号实际可用”是不同证据层级。

## 结论

Seedance 可以列为 AI 写实短剧首选模型系列，具体生产版本应由目标地区的正式接入权限和样片测试确定。不能只根据版本号指定一个不可替换的模型，也不能沿用“2.5 API 尚未发布”的笼统判断：7 月 31 日发布时写 API 即将提供，8 月 17 日更新的海外 BytePlus LAS 官方文档已经列出 2.5 的具体接口。国内火山方舟、本项目账号的实际权限，本次均未核实。[发布说明][release25]、[LAS API][las]

## 官方模型声明

- Seedance 2.0 已采用音画联合生成架构，接受文本、图像、音频、视频输入；参考素材可指导表演、灯光和运镜。不是一个只能把静态图变成无声单镜头的模型。[2.0 模型页][model20]
- 2.5 发布说明强调单次 30 秒、连续多镜头叙事、多轮延长，以及更强的多模态参考；允许用时间戳表达局部音画修改意图，并展示白模参考、绿幕和视角编辑。[发布说明][release25]
- 官网首页写可延长两次，而发布说明用多轮延长描述。未核实各实际产品/API 的累计长度边界；不承诺一次调用生成数分钟，也不把自然语言时间戳理解成逐帧无损编辑保证。[2.5 模型页][model25]、[发布说明][release25]
- 官方同时承认复杂动作物理合理性、多主体交互稳定性仍有改进空间。宣传样片和内部评测不能替代本项目对双人对白、道具交互及连续两集的验收。[发布说明][release25]

## 已读到正文的正式 API 证据

下表仅对应 **BytePlus LAS**，不是国内火山方舟通用承诺。页面最后更新 2026-08-17，服务地区为亚太柔佛。[LAS API][las]

| 项目 | 2.0 | 2.5 |
|---|---|---|
| 模型 ID | `dreamina-seedance-2-0-260128` | `dreamina-seedance-2-5-260628` |
| 单次时长 | 4–15 秒 | 4–30 秒 |
| 输出规格 | 列有 480p 至 4K，部分参考场景受限 | 480p / 720p |
| 音画共生、多模态参考、编辑、延长 | 文档列明支持 | 文档列明支持 |

创建/查询为异步任务；参数包括 `generate_audio`、`callback_url`。结果链接有效 24 小时，应及时归档。该服务含前后处理增强能力，不能把其中所有算子等同于模型原生能力。[LAS API][las]

接入约束：含真人脸的参考图/视频不能直接上传；授权真人素材须申请白名单素材库后使用素材 ID。该条不证明所有 AI 虚构写实人物都被禁止，具体参考素材需验证。[LAS API][las]

文档的 2.5 视频输入限制段存在疑似复制错误，本报告不据此写死参考视频数量/时长。报价、配额、编辑控制精度及目标账号资格仍需接入时确认。[LAS API][las]

## 对工作台的设计建议（产品推论）

1. **质量优先、Seedance 首选。** 首版深度适配一个经过验收的正式接入版本，保留模型/地区/版本能力描述；暂不追求模型数量，也不自动切换到低质量便宜模型。
2. **分镜描述创作意图，不强制一镜一调用。** 同时支持单镜头与一段连续戏/镜头组生成；产出先保存完整片段，再按需要标记镜头区间、选用和裁切。不要要求用户为每个镜头先生成一张图片。
3. **音画联合生成作为主要制作路径之一。** 用户明确角色、台词、表演和声音参考后共同生成，再评审；保留先配音及后配音路径。不要把独立配音/口型服务设成所有镜头必经工序。
4. **编辑与延长作为生成操作设计。** 修改意图、参考片段和时间区间应进入输入快照；产出新候选并比对，保留原版。能否只改指定区域/声音且不影响其他部分，必须由测试确认。
5. **验收整场戏。** 使用同一组虚构角色验证准确台词、声线、视线与反打、动作连续性、局部返工、跨集复用。记录合格交付成本与周期，不以官方单次规格或生成成功率代替质量。
6. **实施前做有界接入验证。** 确认目标地区、账号可开通版本、写实参考素材通路、输入组合、输出规格、编辑/延长能力和费用。上述验证决定首个版本，不影响现在先按先进模型能力设计交互。

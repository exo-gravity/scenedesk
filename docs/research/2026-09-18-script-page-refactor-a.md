## 3. 方案（重构 A）

### 3.1 统一水平基准 —— 建议取 **250**

**建议**：全页统一到 **250**（`h1` 与标签页当前所在的基准），即页面内容的左边界。

理由：
- 250 是 `h1` 与标签页所在的位置,也就是**页面级的左边界**;273 是 `.reader` 自己加的一层内缩,353 是「创作依据」块为了做成 960 宽卡片再加的内缩。
- 参考产品在同类页面都只有**一条**左基准(即梦画布左轨 + 内容单基准;LibTV 顶栏 + 工具轨 + 画布单基准)。
- **具体改动**:`.reader` 的 `max-width:1120px; margin-inline:auto` 改为与父容器同宽（或去掉居中），使 toolbar、分隔线、正文与 `h1`/标签页对齐；空态居中块的居中基准随之与正文列一致。

**⚠️ 需要你确认**：若你更希望**正文保持居中窄栏**（阅读舒适度优先），那就反过来把 `h1`/标签页对齐到 273。**两者只能选一个。**

### 3.2 空态改成"一个主区、两个平级动作"

**建议**：

```
[空态卡片]   ← 与正文列同一左基准
   导入你的初稿剧本
   把已确定的剧本带到这里，与项目成员一起阅读。
   [ 导入 Word ]  [ 从飞书导入 ]        ← 平级两项，进卡片内
   （更多操作 ▾）                        ← 次级
```

- 「导入 Word」「从飞书导入」**从 toolbar 移进空态卡片**,消除 P2 的 40px 割裂
- 去掉 P3 的重复（空态标题与卡片内文案只保留一处说明）
- 依据:即梦画布空态实测「这次创作想从哪里开始?」+**平级两项**（本地上传／选择资产）;LibTV 空态「双击画布/自由生成节点」+ 四个预设平级按钮

**技术影响**：`ScriptImport` / `FeishuScriptImport` 的 portal 目标从 toolbar 占位改为卡片内占位。**有剧本时**（非空态）按钮仍需在 toolbar —— 所以 portal 目标要按状态切换，或改为在两处各渲染一次。

**⚠️ 需要你确认**：有剧本时,toolbar 上保留「重新导入 Word」「从飞书导入」「更多」三项是否合理？还是要进一步收敛（例如导入动作收进「更多」）？

### 3.3 「创作依据」块从剧本页移除

**建议**：**移除底部整块**（含「查看与编辑」按钮），只保留「…」菜单里的入口,并把菜单项文案从「核对创作依据」改为**「创作依据」**（去掉"核对"这一动词性描述,让它读起来是一个去处而不是动作）。

理由：
- 该块**只是入口**（见 §1），内容在 `CreativeWorkspace` 全屏视图里
- 它造成 P6（不在标签面板内却常驻显示）与 P4（与菜单重复）
- 移除后剧本页的职责收敛为**导入 + 阅读 + 出口**

**兜底**：`.../content` 旧深链与「…」菜单入口都保留,不丢可达性。

**⚠️ 需要你确认**：是否接受"创作依据"从剧本页**降级为菜单项**？若你希望它保持可见,替代做法是把它做成**标题行右侧的一个次要按钮**（而不是底部整条band）。

### 3.4 命名收敛（P5）

**建议**：
- 标签页「剧本正文」→ **「正文」**（`h1` 已是「剧本」，标签页再带"剧本"是重复）
- 「剧目设定」标签页**保留不动**（它是 Production 设置,有独立领域含义）
- 导航项 / 面包屑 / `h1` 三处「剧本」保持一致（现状已经一致,无需改）

**⚠️ 需要你确认**：标签页改成「正文」是否可以？（也可保留「剧本正文」不动,只是重复感仍在）

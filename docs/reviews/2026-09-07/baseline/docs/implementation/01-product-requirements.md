# 01 产品需求与验收范围

日期：2026-09-07。设计基线，尚未实现。用户确认的方向见上层完整方案；本包新增的操作细节为下一阶段实施默认值，需在样片或试点证据出现时复审。

## 1. 目标、职责与范围

服务中小工作室内部的 AI 写实短剧生产，不设 10 人组织上限。主要日常职责为主创／AI 制作，另有项目负责人、剪辑与经营决策者；职责可以兼任，不自动增加权限角色。长期广告使用同一项目、素材、执行、版本与交付核心，当前不实现广告业务入口。

首版输出可审阅的完整短剧和必要精剪素材包，允许现有后期工具继续精剪并回传。体验范围从已有剧本／分镜开始，经设定、制作、选择、组接、内部审阅和一次实际返工结束。具体题材、集长和画幅不固定；初始验证样例采用少量角色、对白和简单道具行动。

成功以约定质量下的总人工、现金、日历周期和正确交接评价。模型成功返回、候选数量、点击次数均不能单独作为产品成功指标。未采用候选可能有探索价值，费用照实记录。

## 2. 需求目录

| ID | 功能与行为 | 首版完成条件 |
|---|---|---|
| PR-01 | 登录、工作室切换、内部邀请与固定角色 | 有效成员才能访问；切换不改变旧作业的租户和费用；邀请过期、撤销、重复接受有明确结果 |
| PR-02 | 项目创建、参与者、负责人、预算和归档 | 管理者一次创建项目与剧目；普通成员只访问加入项目；归档禁止新制作但继续归档在途结果 |
| PR-03 | 剧本文本与修订、集场镜结构 | 文本及约定结构录入；编辑、排序和归档保留稳定身份；重拆不清空素材与历史 |
| PR-04 | AI 拆解建议、差异确认 | 只按选定剧本版本及范围生成提案；用户勾选变更后提交；基线过期或映射冲突时重新检查，不盲目合并 |
| PR-05 | 剧目设定、角色造型、场景状态与参考 | 身份、造型、当前状态分别保存；场次默认值在制作前解析为明确输入，已执行内容不随默认值变化 |
| PR-06 | 项目资产、工作室共享、上传和来源 | 所有成功媒体可检索；发布只包含指定资产版本和媒体，不附带来源项目权限；直接使用位置按权限显示 |
| PR-07 | 生成计划与选定范围执行 | 展示实际输入、用途、模型模式、必要限制、预计费用；不能静默丢弃不兼容输入；只运行已核验能力 |
| PR-08 | 作业进度、异常核对与归档恢复 | 提交结果未知不自动再次购买；供应商成功但媒体未归档显示恢复中；重试归档不再次生成 |
| PR-09 | 候选比较、从候选继续、区间采用 | 保留每次尝试；一个镜头可有多个候选，一个媒体可按区间供多个镜头使用；新结果不改变采用 |
| PR-10 | 轻量剪辑与声音 | 顺序、裁切、基本叠加声音、音量、字幕、预览；可形成固定渲染版本；混合音轨是否保留由片段显式控制 |
| PR-11 | 镜头／场次按需审阅、整集确认 | 意见绑定具体对象版本和时间范围；有权负责人作出正式决定；修改后形成新版本 |
| PR-12 | 指定返工、更新剪辑与交接 | 从意见定位来源；重做不覆盖旧素材；显示所选剪辑中替换区间的影响，旧审稿保持原样 |
| PR-13 | 平台导出、素材包、外部成片回传 | MP4、SRT、来源清单及可用素材可交付；回传成片独立审阅；无外部工程时不宣称逐镜可追溯 |
| PR-14 | 基础人工任务与自动制作状态 | 负责人、工序、截止时间、状态和说明；生成／采用／审阅状态从真实记录展示，不要求逐镜重复录入 |
| PR-15 | 预算、用量、费用核对与基础恢复 | 预占与实际消费分离；并发检查一致；未知费用不填 0；备份恢复不重放付费请求 |

## 3. 正常流程与创作自由

1. 管理者创建项目，设置规格与预算默认值，并选定负责人；负责人从已有内部成员加入协作者。
2. 制作人员输入已有剧本，人工或 AI 提案整理集、场次和镜头。AI 结果作为待采纳提案，不直接修改作品。
3. 在当前场次准备足够的角色、造型、空间与声音依据。未使用的高级参数收起；不要求整剧资料完成才能试作。
4. 选择镜头或镜头组，形成生成计划；确认实际输入后提交。每个首版执行计划对应一个供应商任务，批量 UI 可以创建多个独立计划。
5. 结果归档成为媒体。单镜头任务可直接形成候选；多镜头任务先展示整体结果，由人确认各镜头使用区间，不能根据模型描述猜测精确切点。
6. 比较后采用候选；将采用内容加入剪辑并预览。旁白、字幕和配乐可来自导入或已验证的生成路径。
7. 关键镜头／场次按需审阅，最终整集必须确认。候选采用与正式审阅是不同动作。
8. 返工创建新计划和新候选；采用后明确选择更新哪些可编辑剪辑。已审稿派生新草稿，重新提交。
9. 输出平台成片或素材包；外部精剪回传后，确认该文件再形成最终交付记录。

流程允许回到已有设定、镜头或候选继续尝试；不把每一步都变成强制审批门。故事板与动态预演用于检查表达，首版不强制每镜先生成首帧。

## 4. 写实制作要求如何记录

| 要求 | 输入记录 | 观察与判断 |
|---|---|---|
| 人物与造型 | 角色身份、所选造型版本、参考图用途 | 正侧面、表情变化、相邻镜头是否可辨识为同一角色 |
| 空间与行动 | 场景版本、人物位置、视线、动作与道具状态 | 正反打、动作方向、手与物件接触、前后状态是否成立 |
| 对白与表演 | 台词、说话人、情绪、节奏和参考声音 | 字词是否准确、归属是否正确、口型与声音是否协调 |
| 故事与节奏 | 镜头意图、顺序、计划时长与剪辑 | 单镜头可用性和整场可理解性分别评价 |

这些是人工校准的验收维度，不是承诺模型能严格遵守的独立参数。模型无法稳定实现时，允许调整制作路径、补镜头或外部后期；实际人工成本进入评估。首版不建设全剧自动连续性推理或自动打分裁决。

负责人和协作者是项目角色，表中共享读取来自其工作室成员身份。项目任务不扩大访问；同一人可以在不同工作室有不同角色。离职停用使后续访问与未提交作业失效，在途作业仍按原租户归档核账。

## 6. 明确的首版边界

包括一条正式视频主路径、满足样片需要的图片／文本处理及必要声音补充；必要第二模型可因样片前移，不能把“所有模型齐备”作为开工条件。参考版本、基本归档、内部反馈与费用可靠性属于主路径。

暂不建设外包／Guest／客户链接、任意工作流编排、复杂权限、自主无限扩展 Agent、完整专业 NLE、多软件工程往返、模型训练、发行投流或广告完整入口。画布 UX-01 后续验证；低保真暂用结构化制作区，未选择最终界面。

## 7. 外部成片与交付约定

最终交付必须来自已批准的整集剪辑版本或已批准的外部成片版本。素材包可提前导出供精剪，清楚标记为工作材料，不等同最终批准。交付清单记录项目、版本、文件校验值、输出规格、已知素材来源、字幕与确认者；缺失的外部工程信息明确标为未知。

当采用、素材、字幕或声音变更时，已交付文件和历史清单不变；需要更新则建立新版本、新审阅及新交付。项目归档允许已有授权成员读取历史，不允许新生成或编辑。

# 02 信息架构与关键页面行为

本文件规定低保真实现需要表达的行为，画布选择尚未定；不是已验证的视觉设计。需求编号引用 [产品需求](01-product-requirements.md)。桌面网页优先，窄屏以查看、评论与状态为主，复杂制作的移动端交互后续独立评价。

## 1. 导航和工作区

工作室：项目、共享资产、我的工作、用量与设置。项目：概览、剧本与设定、资产、制作、剪辑、审阅与交付。名称是当前原型默认值，后续调整不改变对象。

主要路径为“继续制作当前场次”。工作室及项目名始终可见；深链接恢复项目、场次和选中对象，服务端重新授权。保存最近位置属于用户偏好，不改变项目内容。

低保真布局：左侧集／场次导航，中间镜头及当前状态，右侧选中对象详情；参考与候选可在中间展开，任务进度不遮挡内容。显示上下文所需信息，不同时展开全部参数。支持键盘焦点、明确文字状态和加载提示；不能仅用颜色表达已采用或有风险。

## 2. 页面清单

| 页面 | 默认内容与主要操作 | 空／忙／异常状态 |
|---|---|---|
| 登录与邀请 | 账号登录、接受内部邀请、选择工作室 | 失效邀请、邮箱不匹配、已接受显示不同原因；不自动按邮箱域加入 |
| 工作室项目 | 有权项目、负责人、最近活动、我的待办；管理者新建 | 空项目引导创建／联系管理员；无项目权限不显示项目存在细节 |
| 项目概览 | 规格、成员、预算、制作概况和最近交付 | 未设质量参考提示待补；归档状态只读；汇总不同制作状态而非一个完成率 |
| 剧本与设定 | 编辑文本、查看修订、按范围请求拆解、确认变更 | 草稿保存冲突可比较；提案生成中不锁已有内容；过期提案不能直接应用 |
| 项目／共享资产 | 类型、搜索、版本、上传、引入、直接使用位置 | 未归档媒体不可选；缺必要参考提示原因；共享入口不暴露来源项目 |
| 当前制作 | 镜头意图、参考、实际输入、生成计划、候选与采用 | 缺输入、能力不支持、预算不足、排队、提交待核对、媒体恢复分别展示 |
| 候选查看 | 原尺寸查看、播放、版本信息、区间选取、继续尝试 | 来源输入过时标签；失败作业没有伪媒体卡；候选多时按镜头收纳 |
| 剪辑与声音 | 基础轨道、顺序、裁切、音量、字幕、预览与固定版本 | 不同画幅显式选择 contain／cover；缺媒体阻止渲染；未保存与已渲染状态分开 |
| 审阅 | 固定播放器、版本、时间点评论、决定、来源跳转 | 审稿渲染未就绪不能批准；旧意见不漂移到新时间码；关闭审阅仍可读历史 |
| 交付 | 当前批准版本、生成素材包、下载、回传外部成片 | 工作材料与最终交付有不同标签；导出失败恢复原任务，不重复生成素材 |
| 我的工作 | 手工任务与生成／待审状态分别显示，可定位对象 | 无任务不等于没有制作内容；自动状态不能被手工“完成”覆盖 |
| 设置与用量 | 成员、角色、连接健康、预算、预占和实际消费 | 不显示密钥；连接失效阻止新执行，旧任务仍可核账；未知消费单独显示 |

## 3. 首次成功路径

新建项目表单先填名称；负责人默认预填创建者对应成员，规格默认值可修改，预算由管理者设置。上传／粘贴剧本后，选择人工整理或请求 AI 拆解。未填完整剧目设定也可以进入某一场次。

镜头最初只需表达意图、动作／对白、必要参考与实际模式要求。景别、运镜、声音和其他高级控制按任务展开。多个镜头可选择为一次制作范围，但不自动认定输出按计划顺序含有精确镜头切点。

## 4. 生成前检查面板

展示范围、来源规格版本、最终提示、引用素材预览与用途、模型配置标识、输出要求、预计费用和估计有效期。可返回编辑生成新计划，已提交计划不编辑。

正式按钮文案为“按此计划生成”，明确此次会产生费用。以下情况不可提交：输入未归档／越权、必要参考缺失、能力未启用、估计或配置已过期、预算不足、输入版本已变化。对确实允许的高费用操作使用已有项目预算与单批次确认，不无限新增审批环节。

提交按钮本地禁用只改善体验；实际重复保护由服务端幂等负责。提交响应丢失时使用同一请求键查询／重发；已有作业进入“正在核对提交结果”时不提供普通重新生成按钮，可另开新尝试但必须明确原费用仍可能发生且预算已计入。

## 5. 候选与采用

默认同镜头收纳候选，先看当前采用和最近结果，再展开历史。预览、采用、审阅状态分别表示，查看过不等于采用。视频对比首版支持顺序播放／切换，不提前承诺帧级同步比较。

采用操作必须包含媒体使用区间；连续素材拆成多个候选时各自保存区间，不复制媒体文件。当前镜头规格已变时，展示候选对应旧规格及差异，允许明确沿用旧结果：建立关联到当前要求的新候选，并保留 sourceTakeId，再执行采用，不假装旧结果已自动满足新要求。

采用成功后列出直接使用旧结果的剪辑草稿，用户选择要更新的稿和片段。若新旧时长不同，替换预览显示区间越界、声音及后续时序影响；不静默拉伸、覆盖或改变所有下游。用户也可稍后处理，界面显示“当前采用与该剪辑使用不同”。

## 6. 剪辑、提交审阅与返工

草稿持续保存，手动“生成审片版本”固定内容并启动渲染。每次固定版本有明确名称／序号、来源草稿版本与输出规格。源媒体发生新生成不会改变该版本。

点击时间码评论定位到实际观看文件；评论可有结束时间，超出视频长度拒绝保存。镜头候选审阅使用候选局部播放器时间，后台同时保留对应源媒体偏移。负责人作出通过／需修改决定；每轮决定关闭该审阅，重新确认创建新的审阅轮次，不覆盖旧决定。

返工从评论打开来源；外部成片若仅有文件和交接清单，则展示这些已知内容并由用户人工定位，不能虚构逐镜映射。制作人员继续尝试，产生新候选并更新所选草稿；新稿重新审阅。

## 7. 保存与多人修改

可编辑对象使用版本号。保存时版本不同返回冲突：保留本地未保存内容，展示服务器最新版，可复制文本或手动合并后重新提交；不直接 last-write-wins。镜头排序对 ContentTree.revision 检查，剪辑整体保存检查草稿版本。

首版可每个页面处理小范围对象冲突，不提供实时多人光标或逐字协同。上传和生成任务在离开页面后继续，用户回来可恢复进度；浏览器不能作为唯一运行状态保存点。

## 8. 关键文案与错误恢复

| 情境 | 应表达的事实 | 下一步 |
|---|---|---|
| 提交响应未知 | 供应商可能已接受，正在核对；本次预占仍保留 | 查看作业；不能把重新 POST 包装成安全重试 |
| 生成成功、归档失败 | 结果已生成，正在恢复素材保存 | 重试归档；显示来源有效期风险给运营处理 |
| 旧输入结果 | 该结果使用了此前的镜头／参考版本 | 查看差异，保留、继续或明确采用 |
| 已审稿变更 | 本次修改会生成新稿，旧稿及批准保留 | 从旧稿派生草稿 |
| 权限撤销 | 当前无权继续访问 | 停止轮询、清理页面敏感缓存、返回工作室选择 |
| 预算不足 | 展示有权读取的已用、在途、剩余及本计划估计；工作室总账仅管理者可见 | 调整计划或由管理者调整预算 |
| 配置已更新 | 本计划的模型配置已变化，需要重新检查 | 重新生成计划，不静默升级模型 |

## 9. 埋点与验收观察

只记录必要操作事件：进入制作、计划形成／提交、候选查看／采用、开始返工、剪辑固定、提交审阅、决定、导出和下载。使用项目内对象标识及耗时，不把提示词、剧本、私有媒体 URL 和密钥写入分析日志。记录失败原因与来源（客户端／服务端／供应商），区分人工活动和异步等待。

UX-01 后续比较时保持生成、参考、版本能力相近；当前页面稿只证明行为设计可走查，不能宣称用户效率已提高。

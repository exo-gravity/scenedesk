# 07 模型接入、能力配置与验证规程

目标是接入一条稳定的写实短剧主路径；Seedance 优先评估。模型品牌、网页端体验、API 服务、账号权限和执行模式不是同一个概念。此处不承诺某个尚未核验的版本支持所有参考、对白、声轨、取消或幂等。

## 1. 本轮核对得到的工程约束

- 官方火山方舟 Python SDK 在本轮查阅版本中的默认重试为 2，创建任务也会经过请求层。客户端关联 ID 不能自动证明供应商创建幂等；适配器需要关闭创建端隐式重试，并检查自身实际使用的客户端与代理配置。[固定版本 SDK](https://github.com/volcengine/volcengine-python-sdk/blob/bd7d94433803d213a85f918ff2eb049067655eff/volcenginesdkarkruntime/_constants.py)
- 官方 SDK 具有内容生成任务的创建、读取、列表与删除接口；类型存在不代表指定账号、模型和模式具备全部能力。[官方任务资源定义](https://github.com/volcengine/volcengine-python-sdk/blob/bd7d94433803d213a85f918ff2eb049067655eff/volcenginesdkarkruntime/resources/content_generation/tasks.py)
- BytePlus LAS 的特定区域文档存在任务与结果有效期、真人参考访问条件及不同算子收费规则。它们不能直接迁移为中国区方舟或所有 Seedance 接口的统一规则。
- 本轮未找到足以把所有相关回调都视为已认证、严格有序且恰好一次送达的依据。默认把回调当查询提示，费用和媒体状态以可信查询／账单证据确认。

详细访问记录、适用范围与原始链接见 [模型接入证据](../research/2026-09-07-implementation-model-evidence.md)。本包中的“默认禁重试”是据此做出的系统设计，不是对供应商实现的推断。

## 2. Capability Profile

每条启用能力固定 connectionId、供应商服务、地区、账号、模型版本、模式、计价版本、验证时间和证据。不同账号或地区不可共用一次通过结论。公开 API 返回界面需要的限制；内部配置额外保留恢复、计费、文件期限与验证用例结果。

| 配置组 | 必须说明 |
|---|---|
| 输入 | 文本；图／视频／音频类型；用途映射；每类数量、尺寸、时长、大小；真人参考条件 |
| 模式 | 文生、图生、多参考或其他实际支持模式；不能由一个宽泛 supportsReferences 布尔值替代 |
| 输出 | 时长、画幅、分辨率、帧率限制；是否原生音频；混合轨还是分轨；是否允许首尾帧同时使用 |
| 生命周期 | 创建与查询地址、状态映射、轮询间隔、任务保留期、结果链接有效期、取消及恢复语义 |
| 消费 | 估计公式和输入、币种、费用来源、失败／取消计费、内部重试是否产生多笔费用 |
| 可靠性 | SDK／代理重试设置、已测试的幂等或找回能力、回调校验、限流和错误分类 |
| 数据处理 | 输入上传路径、供应商保存期限、地区和适用协议；实际采购确认后填写 |

未验证项使用 unknown／未启用，不能以 false 隐含“不可能”或以 true 推断可用。管理者可停用连接，但不能自行把未验证的能力勾成已验证。首版由受控配置发布能力，无需建设面向用户的通用适配器管理平台。

## 3. 接口边界

以下为模块接口设计，真实 TypeScript 类型在实施时由 contracts 包落地；不是可直接调用的供应商 SDK。

| 操作 | 输入 | 返回与责任 |
|---|---|---|
| prepare | 固定创作输入、能力配置、已验收媒体清单 | 规范化请求、输入清单、请求摘要、估计或明确阻断；不执行付费生成 |
| stageInputs | 已保存 plan、媒体读取授权、连接 | 必要的供应商上传引用及期限；逐项保留 mediaId 映射；只有已核验安全性才可恢复上传 |
| submitOnce | 持久化 attempt、PreparedRequest、原连接凭据 | Accepted(providerJobId, receipt)／Rejected(evidence, billingState)／Unknown(correlation)；不吞未知为普通失败 |
| query | 原连接、已知 providerJobId | Pending／Running／Completed(outputs)／Failed(evidence)／Cancelled(evidence)／Unavailable(reason) |
| recoverSubmission | attempt 证据与具备已验证找回能力的原连接 | Found(providerJobId)／ConfirmedNotAccepted(evidence)／Unresolved；unsupported 直接 Unresolved |
| requestCancel | 已知 ID、原连接、已核验能力 | Requested／ConfirmedCancelled／Unsupported／Unknown；均不自动产生退款 |
| readCostEvidence | 作业回执或官方账单定位信息 | Confirmed(entries)／Pending／Unsupported；Unsupported 转人工账单核对，不记 0 |

媒体归档由 AssetMedia 负责，供应商 Adapter 只返回来源定位与期限。文本同步 API 可以返回直接完成的提案源数据，由 Generation 进行结构和范围校验；不能伪造一个可查询的 providerJobId。所有调用记录 correlation；密钥不进入 PreparedRequest 的可见快照或 request hash。

prepare 的实际输入必须可回显：使用了哪一版角色和造型、哪些媒体、每项用途、文本如何形成、哪些条件不受支持。不同模型路径可以有不同必填项。支持直接多参考时，不强制先生成首帧；只支持首帧时，界面明确需要准备该输入。无法映射的声音／动作参考返回阻断或由用户明确移除，不能静默忽略。

stageInputs 若使用会计费的预处理算子，必须成为显式计划与预算项，不能隐藏在“上传”里。首版优先选择免费媒体上传或授权 URL 输入；如必须采用付费预处理，先更新计划和费用契约再启用。

## 4. 作业输出与候选

| purpose | 成功后的平台对象 | 失败边界 |
|---|---|---|
| video | 原媒体、必要元数据；单镜头可形成候选，多镜头由人映射区间 | 无法验收文件为 archive_failed；画面不好可仍 succeeded，由人不采用 |
| image | 图片媒体，可用于角色、造型、场景或实际生成输入 | 成功返回与角色设定确认分离，不自动替换资产当前版本 |
| audio | 音频媒体，可显式编入时间线 | 不因文本相同就自动覆盖镜头原生音轨 |
| script_analysis | 通过 schema／作用域／父子关系校验的 Proposal | 非法提案为 failed，不写入剧本结构；费用照实核对 |

一项视频任务可能包含多个镜头，也可能只完成某个镜头的一部分。Provider 输出的段落描述或台词时间不是精确剪辑依据；候选区间由验收媒体及人的选择确定。模型提供结构化切点时也要先校验再呈现。

## 5. 连接验证清单

在所选账号上执行并保留请求摘要、实际回执、文件参数、费用和结论，密钥与私有内容脱敏。真实调用需要已确定的采购账号与测试预算；文档静态校验和模拟器均不能代替本节。

| ID | 必须验证 | 可启用条件 |
|---|---|---|
| MV-01 | 最小输入到可播放输出 | 原文件及时归档、参数与报价依据可解释 |
| MV-02 | 同人物多参考／所选造型，或该模式替代输入路径 | 支持的输入角色确实送达；效果由行业评审记录 |
| MV-03 | 双人对白与短动作 | 明确原生音频是否可用、音轨形式、常见返工路径 |
| MV-04 | 创建超时与进程中断 | 实际调用栈不自动重 POST；未知能被显示和核对 |
| MV-05 | 已知 ID 查询、限流与暂时错误 | 重查可恢复，错误和过期状态映射正确 |
| MV-06 | 输出 URL 过期／下载中断 | 可以恢复或明确不可恢复；未再次购买 |
| MV-07 | 取消与成功竞态 | 保存真实结果并核对消费，无“取消即退款”假设 |
| MV-08 | 用量与账单核对 | 正常、失败和内部重试费用可关联；不明时保留预占 |
| MV-09 | 真人素材与所选服务访问条件 | 指定账号确实允许预期输入，输入资料符合该服务约定 |
| MV-10 | 密钥轮换、停用与旧任务查询 | 新任务停用生效，已提交任务可核对；原账号身份不丢失 |

主路径入选以约定质量下的可采用率、人工修改分钟数、实际成本和交付周期共同评估。若直接音画路径对白不可控，可以采用原生视频静音加外部配音／补镜头，但新增步骤计入成本。不能只比模型返回成功率或单次报价。

## 6. 首版与演进

S0 先做一个模拟 Adapter，覆盖接受、拒绝、响应丢失、查询延迟、取消竞态和过期文件；随后接入一个真实视频模式。图像和文本能力只做到样片所需，独立语音在主路径需要时接入。实现第二供应商时再检验接口是否过度贴合第一家，不提前实现大量空适配器。

长期新模型接入只应修改能力配置和 Adapter，以及确有不同输入需求的计划表单；不应改变镜头、采用、冻结审阅和租户费用规则。若未来供应商提供长段自主创作，仍保存明确输入与输出版本，由业务模块决定如何拆成镜头或广告创意；不让供应商任务结构成为全平台数据模型。

# 10 制作、返工与交付夹具

本夹具为虚构素材，用于验证系统主流程和连续性，不代表已经生成或通过的样片，也不限定产品的剧种、镜头数量和单集时长。最终市场验证仍需目标工作室真实项目。

## 1. 创作任务

片名《旧钥匙》。表现形态：写实悬疑对白。人物只有林夏、周衡两位成年人。场景 A 为夜间咖啡厅卡座，场景 B 为相邻走廊。计划总时长 46 秒，测试规格 720×1280、24 fps、普通话；模型输出实际规格另按已验证模式选取，剪辑时归一。

创作基准：林夏穿灰色风衣，周衡穿深色外套；咖啡厅有暖色桌灯；旧黄铜钥匙只有一把，带红线。场景 A 前半钥匙在桌面靠周衡一侧，后半由林夏右手拿起。场景 B 林夏保持同一服装与钥匙。角色各准备身份参考和所选造型参考，声音可以先用合法导入录音。人物、声音和图片素材须由实施团队实际准备，此文没有假造媒体文件或授权。

## 2. 集场镜与计划

| 镜头 | 场次／计划时长 | 意图、画面与台词 | 需观察的连续性 |
|---|---|---|---|
| SH-01 | A／7 秒 | 双人中景建立桌子关系；林夏看向周衡：“你说，东西一直在你这儿？” | 两人座位、视线、桌灯与钥匙位置 |
| SH-02 | A／8 秒 | 周衡近景：“我答应过你父亲，等你回来。” | 反打视线、服装、说话人和字词 |
| SH-03 | A／6 秒 | 手部近景；林夏右手拿起带红线的黄铜钥匙 | 手与物件接触、钥匙唯一性、拿起方向 |
| SH-04 | A／9 秒 | 林夏近景，看钥匙后抬眼：“可这把钥匙，是我昨天才丢的。” | 人脸、口型、右手及红线细节 |
| SH-05 | A／8 秒 | 周衡望向走廊入口，压低声音：“那就别开那扇门。” | 门的方向、情绪、静默节奏 |
| SH-06 | B／8 秒 | 林夏在走廊门前停住，右手握钥匙但没有插入锁孔；保留停顿 | 服装与钥匙保持，空间转场可理解 |

生成单元不固定等于镜头：先选择已验证模式支持的单镜头路径；需要验证多镜头模式时，可将 SH-02／03 作为一个任务输入并人工标定输出区间。计划时长是剪辑意图，不是要求模型精确返回相同时长；不足时调整剪辑或明确新开任务，不能悄悄循环补帧满足时长。

## 3. 操作与预期记录

1. Owner 建立工作室、预算、项目与负责人；两位协作者分别制作 SH-01–03、SH-04–06。
2. 导入上述剧本文本和资产，形成集／场次／镜头；若用 AI 拆解，先检查并选择提案，保留 script revision 与 base content revision。
3. 每次生成前查看角色、造型、动作和声音实际输入，确认模型模式及估计；执行后等待原媒体验收。候选列表显示所有尝试与费用状态。
4. 制作人员为各镜头采用候选，明确加入同一集剪辑；处理原生音轨、补充声音和字幕。冻结“审稿 A”，完整回放后发起整集审阅。
5. 负责人对 SH-03 的手与钥匙接触问题提出带时间码意见，并对整集标记需修改；旧审稿 A、评论和下载文件保持不变。
6. 重做 SH-03 产生候选 B；先不采用，验证当前剪辑完全不变。采用 B 后，系统提示受影响草稿；用户仅更新选定剪辑范围，检查时长变化后的声音与字幕位置，不默认移动所有后续内容。
7. 冻结“审稿 B”，检查修复镜头及相邻接续；负责人批准最新整集版本，导出 final MP4、SRT、素材和清单。
8. 作为第二种返工，改晚礼服造型参考但不改本片所用灰风衣；确认旧计划、审稿及交付没有变化。若改灰风衣，也只能影响新计划，不覆盖既有镜头。
9. 可选外部精剪路径：导出 working 包，在外部工具修改片段后回传成片，按新外部版本审阅和最终交付；没有工程映射时不自动把评论定位到 SH-03。

## 4. 样片评价与记录

每一轮保存计划、候选、采用、剪辑版本、评论、费用证据与交付校验值。行业评审至少分别评价身份／造型、空间／道具、对白／表演、故事／节奏，以及是否需要外部修复；采用“可用、需局部修复、需重做”并写明理由，不用一个平均分掩盖关键镜头失败。

| 指标 | 记录方式 | 注意 |
|---|---|---|
| 人工投入 | 剧本整理、参考准备、生成操作、挑选、返工、剪辑和审阅的实际分钟数 | 模型等待与人实际操作分开 |
| 成本 | 已确认生成费用＋未决预占＋其他真实服务费用；存储／计算另列 | 未决不算 0；预占不与已结算再重复相加 |
| 周期 | 从拿到剧本到可批准版本的日历时间及主要等待 | 团队并行工时不能直接当日历周期 |
| 质量 | 每镜可用性与整场可理解性，关键问题和修复路径 | 技术 succeeded 不代表创作已通过 |
| 交接 | 错版本、重复引用、意见无法定位、外部工具返还造成的信息缺失 | 记录实际事件，不以点击减少代替 |

样片结束时产出实测记录与缺陷清单，决定是否增加制作路径、缩小首发题材或调整编辑能力。画布交互若另行研究，应使用同一类任务与质量标准，避免把更好的样片素材误当成更好的交互。

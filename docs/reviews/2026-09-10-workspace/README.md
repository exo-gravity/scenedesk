# 核心工作区三方独立评审与综合裁决

日期：2026-09-10。状态：评审完成；最终推荐待用户设计评审，尚未修改页面或进入工程。

按用户要求，由三个独立 AI 代理分别模拟资深设计师的审查视角。它们不是受聘真人设计师，也未开展工作室用户访谈。三者先阅读同一套共同语言、原型与截图，形成自己的判断，再对照主代理前一轮建议；未互读对方报告。主代理最后阅读全部报告并独立裁决，未用多数票替代产品判断。

## 主要裁决

| 议题 | 评审差异 | 主代理裁决 |
|---|---|---|
| 分镜默认状态 | 创作评审允许初次先总览；另两份强调恢复既有聚焦结构 | 已有镜头默认主预览＋底部分镜条，恢复最近位置；网格由“全场总览”打开。空场使用建分镜引导，不增加必经总览 |
| 助手模态抽屉 | 三方一致不适合持续辅助 | 改为非模态停靠；画面和真实输入可继续操作；目标固定与非模态同时设计 |
| 输入位置 | 三方倾向稳定中央输入；视觉评审指出这会改变既有右侧输入规定 | 推荐中央底部限高输入，明确标为新布局提案；第 18 文档不在本轮静默改写 |
| 1366 同开完整资产库与助手 | 视觉评审愿以较紧尺寸试验；创作与信息架构评审反对默认双开 | 不作为 1366 默认或验收要求。优先助手＋直接输入＋固定参考，完整浏览按需切入；宽屏足够时可双开 |
| 右侧详情／助手页签 | 主代理此前仅视作过渡；信息架构评审认为可长期成立 | 接受其纠正：右侧低频详情／助手可以互切，真实提示词留在中央，不能整份制作输入与助手互斥 |
| 关键参考 | 多份报告指出持续看图不同于持续开素材目录 | 允许将关键参考固定到中央预览区；保留仅查看、生成参考、助手引用三种明确用途 |
| 返工自动改提示 | 创作与信息架构评审发现确定的源码行为 | 返工入口只定位并附来源；修改须明确应用建议，不自动覆盖旧草稿 |
| 全局导航 | 三方均支持基本层级 | 保留工作室／项目／场次；压缩物理行数、统一名称、补版本列表，不重做全局结构 |

## 证据边界

代码与截图支持现状问题；前轮主代理浏览器测量支持遮挡和模态阻断。三份评审没有分别重复所有浏览器实测；尺寸提案和效率收益尚未通过目标团队验证。当前原型共用静帧、有限模拟动作，不足以证明真实模型效果、视频比较、持续对话或生产质量。

本轮仅增加设计文档与索引。下一步仍是设计原型验证，不是启动后台、真实模型或生产工程。

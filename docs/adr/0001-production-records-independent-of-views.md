# 制作记录与画布、剧集呈现分开

当前默认将短剧的剧目、场次和镜头放在内容 Module，将媒体、生成、采用、剪辑和交付作为明确记录；画布位置不成为它们的唯一归属或身份。相比统一任意节点存储，这增加了少量显式关联，但能校验版本、授权和下游影响，并使未来广告不必创建虚假的剧集层级。首版呈现已按用户最新决定升级为场次分镜／自由画布双模式，数据与视图分离原则保持；具体新增边界由[ADR-0006](0006-scene-canvas-and-versioned-drafts.md)补充。

接受日期：2026-09-07。依据用户授权自主评审与裁决，纳入本期实施基线；不代表外部真人签字或运行验收。

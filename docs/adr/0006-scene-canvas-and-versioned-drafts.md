# 每场一张通用画布，布局草稿与制作事实分开

2026-09-09：用户确认首版在整个场次内提供分镜／自由画布两种模式，并授权完成剩余设计。通用画布保存文字、媒体引用、生成草稿及空间组织，短剧接入层负责每场唯一画布和镜头关联；采用、实际剪辑与批准继续由原业务模块拥有。由此，广告未来可直接绑定广告任务，切换视图也不会重建制作内容。

首版选择整个画布文档的 revision／If-Match 乐观并发保护，保留本地未保存恢复副本；不采用无条件最后写入覆盖，也暂不引入 CRDT 或实时共同编辑。代价是两个成员修改不同节点也可能发生保存冲突，换取可验证的提交与恢复规则；自动三方合并仅可在后续单独验证后增加。生成与费用记录独立于文档保存，避免异步结果覆盖用户画布或产生重复消费。

具体数据、接口、跨模式绑定、输入快照和冲突处理见[18 画布工程设计](../implementation/18-canvas-workspace-contract.md)。本次是实施设计裁决，不代表服务端已实现。

# 未完成编辑与可渲染剪辑分别保存

2026-09-10，用户确认技术方向并授权设计收尾。每个 timeline Cut 设一份团队共享的 CutWorkDraft，自动保存尚未完成的编辑；CutDraft 继续只接收已确认的归一结果，固定版本仍以实际渲染文件审阅。这样不会为了保存工作而放松渲染规则，也不会让用户先解决全部声音字幕问题才能关页。

两者使用独立 revision；归一固定工作稿来源，采用结果时同时检查 Cut 与工作稿版本。此次选择独立工作稿，没有把 Cut 的状态扩为同时可恢复、可渲染和可批准的混合状态。具体协议见[21](../implementation/21-technical-baseline-closure.md)，真实保存与渲染仍待实现验证。

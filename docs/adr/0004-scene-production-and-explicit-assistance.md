# 以场次承接制作，AI 建议通过明确采纳进入业务

状态：accepted，2026-09-09。用户选择“一位制作人员主责完成一场戏”为核心主场景；场次制作页用制作／剪辑／审阅共享同一组对象，完整 MVP 仍交付整集、跨集复用和后期交接。分镜建议可直接追加当前场次，提示和返工建议独立保存；结构采纳、费用执行、剪辑使用和正式批准分别记录，以保留试作自由和可追溯的团队决定。

通用画布或自主 Agent 不承担业务事实源；后续可新增视图及自动化入口，不改写历史身份和授权。代价是多维护少量明确关系与快照，换取旧稿、未知提交及新尝试不会互相覆盖；具体规则见 [收口基线](../implementation/14-scene-mvp-closure.md)。

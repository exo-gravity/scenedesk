# 复用任务队列，业务执行资格独立保留

2026-09-10，用户确认技术方向并授权设计收尾。通用领取、延期、重试和回收交给成熟队列，不再建设自研 worker_tasks 调度表；业务作业、尝试、预算、未知提交和外部在途额度仍由业务模块维护。队列重复执行只能重查业务资格，不能再次购买同一个不确定提交。

pg-boss 为首个集成验证候选，须证明业务事务内入队、受限角色和故障恢复后才锁定；未通过则重新裁决适配方案，不能退回无记录的双写。事件 outbox 继续承载项目通知，不重复转发同一个内部任务。边界及验收见[21](../implementation/21-technical-baseline-closure.md)；此 ADR 接受的是组织与可靠性策略，不宣称候选已集成。

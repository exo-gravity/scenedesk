# LibTV 主创作工作区：官方资料复核

研究日期：2026-09-14。此次对应用户要求重新审视整个创作场景、以自由画布为主要交互的方向。只读取公开官方网页、官方发布说明和官网已确认链接的操作文档；未登录、创建项目、触发生成、安装插件或操作主任务浏览器。

**结论：一手资料支持把画布上的创作对象及其关系作为主工作面，把 Agent 接到同一作品；目前取得的公开证据不足以逐像素复刻 LibTV 的节点输入框或右侧聊天栏。** 因而整体调整应围绕“在当前材料旁继续创作”，不能仅把原来的工作表、状态面板换位置，也不能把尚未观察的控件位置写成 LibTV 事实。

## 证据口径

- **亲见 UI**：本轮独立查看到的工作区截图或连续操作。此次背景研究没有取得可显示的完整工作区帧，因此不作此类主张。主任务正在独立浏览官网，其新观察须另附对应截图或时间点后并入设计结论。
- **官方文字**：实际读取的官网文字、官方账号视频说明或官方分发仓库文档。它证明产品介绍或操作约定，不等于浏览器交互验收。
- **未知**：资源无法读取、只有营销名称，或文字不能证明的空间与手势细节。

旧报告 [libtv-canvas.md](./2026-09-14-libtv-canvas.md) 是线索索引，不作为本次新增观察。旧报告中主任务对视频约 24.88 秒资产网格、43.39 秒媒体与连线的观察，也没有被改写为本研究本轮亲见。

## 两项容易导致错误设计的证据误读

**“右侧画布”不等于“LibTV 右侧 Agent”。** 官方 `libtv-production.md` 的 “Mandatory Right-Panel Canvas” 明确指把准确的 LibTV 画布打开在 **Codex 右侧浏览器面板**，目的是让外部 Agent 的修改可见。它不能证明 LibTV 内部 Agent 栏的位置、尺寸或交互。[原文](https://github.com/liblib-ai/marketplace/blob/faa53b625f72911616100d6b3d9560b5c3b9de80/plugins/libtv/skills/music-driven-product-ad/references/libtv-production.md#L13-L20)

**“脚本节点”不等于“独立脚本页面是创作前置”。** 官方视频确实介绍脚本节点及批量产出，但没有在可读说明中规定用户必须先完成脚本或镜头目录才能创建媒体。反过来，也不能根据自由画布定位声称 LibTV 没有故事板视图。[原说明](https://www.bilibili.com/video/BV1jEQzBNE3K/)

## 后续整体方案应回答的五个问题

以下是依据上述一手语义提出的 SceneDesk 设计验证项，不声称是 LibTV 已验证行为。

1. **打开场次后的第一眼是什么？** 主区域应让用户看见已有画面、文字与创作关系。全局页面框架和检查状态可以存在，但不应把画布压成表单旁的预览窗口。
2. **从已有画面继续需要几次跳转？** 节点旁能够发起派生、说明引用和输入要求，并回到实际结果；不要要求先切任务列表、找计划，再回画布辨认来源。
3. **选中后哪些内容出现、失去焦点后哪些内容保留？** 主要输入就近可编辑，固定模型/引用/输出值可核对；未保存、冲突与未知任务不能因面板隐藏丢失。布局优先级变化不意味着放松业务持久化。
4. **助手如何讨论正在看的东西？** 对话清晰显示明确收录的材料和当前要求，建议可继续改稿；修改目标和应用结果可核对。不要把生成配置长表伪装成聊天。
5. **脚本与分镜何时介入？** 让结构化叙事成为用户明确选择的整理与生产工具，同时保留从单张图、文字或声音直接探索的入口。后期剪辑、公开团队运营仍不是本轮必要范围。

## 尚需主任务亲见补证的最小清单

| 所需画面 | 必须记录的事实 |
| --- | --- |
| 未选中对象的完整工作区 | 页面 chrome、画布占比、常驻入口、Agent 是否已打开；不能只截放大的节点 |
| 同一媒体节点未选中 → 选中 → 输入 | prompt 与参数相对节点的位置、如何进入编辑、是否遮挡材料 |
| 由一个节点继续创建另一节点 | `+` 或连线动作、类型菜单、实际引用呈现、结果与来源的空间关系 |
| Agent 开/关及明确收录上下文 | 面板在工作区中的位置、画布是否缩小、选区如何变成对话材料 |
| 脚本节点展开与一次结果取回 | 结构字段、与媒体的关系、历史或分支入口；不把宣传“批量”当成实测多选 |

这五项足以校准主场景的信息架构。没有取得的内容继续标为未知，不使用同名开源克隆、未证实官方身份的教程账号、第三方商业介绍或网页 bundle 中的组件名填空。

## 1. 打开方式

运行中的地址：[场次制作](http://127.0.0.1:4311/#/scene/production)。开发服务关闭后，在仓库根目录执行 `npm ci`、`npm run dev:web`，再打开同一地址。该视觉原型可独立运行，不需要模型账号或数据库。

建议先看场次制作，再切换剪辑、审阅；之后通过左侧导航查看资产、戏文和项目。最后看 [视觉规范](http://127.0.0.1:4311/#/design/)，判断整体方向是否适合团队长期使用。

## 3. 视觉方向

- **深灰基底与暖杏色主操作**：工作台 `#111212`、内容层 `#191B1B`、输入／选中层 `#252828`、主要动作 `#EDB878`。状态另用带文字和图标的低饱和绿、琥珀及红色。
- **中文桌面产品排版**：系统中文无衬线为主，页面标题约 24–30 px，区域标题约 14–16 px，主要正文约 13–14 px，辅助信息约 10–12 px。编号和时间使用等宽数字。项目封面使用单独的剧名表现，不混入日常操作标签。
- **场次制作以画面为中心**：宽桌面四列故事板，较窄桌面减少列数；右侧只展开当前镜头的要求、候选或参考。保留竖屏完整画幅，不为填满卡片裁掉分镜内容。
- **不同任务使用不同工作区**：戏文是阅读编辑布局；资产是可筛选的视觉库；剪辑把播放器和轨道放在中心；审阅同时展示具体稿件与意见。
- **稳定操作反馈**：原生模态对话框、键盘焦点、Esc 关闭、按钮禁用与文字解释；尊重减少动态效果偏好。桌面优先，窄屏折叠导航并顺序展开面板。

本次使用虚构的拾光工作室、《旧钥匙》与三位示例成员；品牌“片场”只是视觉占位名称。没有最终确定品牌、产品命名或上线承诺。

## 4. 重点走查路径

1. 打开制作页，选择 SH-04，进入“候选”。采用 B，检查剪辑仍使用 A。
2. 点击“更新剪辑草稿”，在确认框核对 A → B，保持已有时长；确认后再进入剪辑。
3. 调整某个片段的顺序或示意时长；播放静帧预演，生成新的审阅快照。
4. 切回 v1，核对它仍使用原候选、保留原意见；新稿不会继承旧决定。
5. 在新版本某个时刻添加意见，选择“准备修改”，核对版本、时间点和来源镜头。
6. 模拟生成几个候选，检查它们只增加到对应镜头，未自动采用或替换。
7. 模拟确认场次后到整集页，检查可选择该场次版本，但缺少其他场次和整集确认时仍不能最终交付。
8. 在设置页重置示例，可重新开始。

## 5. 原型边界

制作数据保存于当前浏览器的专用 localStorage 键，可跨刷新保留；不是后端持久化或协作数据库。真实用户身份、服务端授权、预算、生成任务、媒体验收和业务接口尚未接入。新项目表单仅建立本地卡片，完整新项目流程待业务切片实现。

播放器按示例时长切换静帧，**没有真实运动画面或音频播放**。音轨波形是布局示意，字幕按关联片段展示；时长滑块不代表专业裁切或帧级时间处理。生成按钮明确写作模拟，不请求模型，也不产生费用。固定版本与主创决定只在本地演示状态中发生。

图片导入只在当前资产页面会话显示，离开页面后需重新选择，不上传到服务。示例清单下载为真实 JSON 文件，明确不含原片、MP4、SRT 或正式交付成果。内部后期回传与尚未满足条件的最终交付展示设计状态。

Storyboard 的视觉组织与关键操作在此可评估；无限画布和任意节点连线仍是 UX-01 后续验证项。

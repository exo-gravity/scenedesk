# 统一资产库 · 2026-09-15

用户在讨论素材与创作资产的关系后，同意以小云雀截图中的直接分类方式改善前端，并明确要求实施。此决定调整前端组织方式，不合并媒体文件与创作资产的领域身份。

## 已接受方向

- 用户随后指定项目导航为「剧本 → 场次 → 资产」，严格按此顺序。工作室入口叫「资产库」，项目「资产」进入同一个资产库浏览页。项目内通过「当前项目 / 工作室共享」切换范围；分类不再要求先选“素材文件 / 创作资产”。
- 直接浏览角色、场景、道具、风格、图片、视频、音频；低频文本与声音设定在“更多”。窄屏允许分类自然换行，不能挤窄文字或产生页面横向滚动。
- 当前项目自建资产和已引入的共享固定版共同进入图库，后者标明来源与确切版本。共享当前版变化不能更新项目已引入版本的参考封面。
- 媒体先预览或播放，创作资产先阅读设定和参考。版本、来源及使用位置按需展开；已有草稿恢复、确认、归档和权限错误继续可处理。
- 图片可以显式选择角色并准备加入参考；只有保存新设定版本后才形成正式关联。画布直接使用文件与引用角色设定仍是两条合法路径。

截图仅作为信息组织参考；不据此假设其后端模型。3D 导演台、多轨道剪辑不加入本次范围。卡片不显示无法从现有分页 API 得到的总数量或虚构使用次数。完整的素材反向使用索引、私有资产发布共享和独立复制继续按各自领域契约推进。

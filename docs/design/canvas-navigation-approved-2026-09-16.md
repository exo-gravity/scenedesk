# 剧本选文、画布切换与场次目录：已确认设计

2026-09-16，用户在三个效果图后明确要求「好，同意上面的改动，落地吧」。三个页面属于同一方案，细化[创作工作区](creative-workspace-approved-2026-09-16.md)，不重新拆分成多个独立制作台。

参考图：[剧本](canvas-navigation-2026-09-16/script-approved.png)、[画布菜单](canvas-navigation-2026-09-16/canvas-approved.png)、[场次目录](canvas-navigation-2026-09-16/directory-approved.png)。生成图中的媒体和数量是示意，不能替换真实业务内容。沿用既有 Mantine 主题、Phosphor、216px 可折叠左栏和恢复机制，不重做品牌系统。

- 剧本页服务导入、阅读和引用。去掉主按钮「整理为镜头」；原助手收进「更多 → 分镜建议」。明确选文、确认后才能带入项目画布；不自动分析整个剧本或执行模型。
- Word、飞书、更多历史操作和选文组成一个工具栏。正文可直接选文，唯一且精确匹配原稿时预填引用；重复文字或复杂排版无法准确定位时回到规范原文选择。保留原件、固定稿、来源与未完成请求恢复。
- 左侧主导航保持「剧本、画布、项目资产」，移除底部「场次管理」。项目画布和场次画布共用导航；左上画布菜单包含项目画布、按集分组的场次、搜索、新增场次、场次目录。
- 主入口先验证当前权限和现有画布，回到本标签页最近使用的有效画布；仅一张现有画布时直接进入，多张且无有效记录时明确选择。明确进入项目画布使用 `?scope=project`，避免被最近场次重定向。历史地址绑定具体画布，浏览器返回不重新猜目标。
- 场次目录位于画布之下，按集呈现轻量列表。首要操作为新增场次，每行打开画布；镜头计数进入现有镜头列表，详情就近打开抽屉。重命名、排序、归档、旧要求历史和导入工具按需展开。
- 新建场次先提供名称、所属集、梗概、时间、地点；连续性状态和默认资产属于高级设定。没有单集时明确新建，不能隐式创建或丢弃已经输入的场次草稿。

旧 `/production?scene=…`、`/content?scene=…`、`?shot=…` 与固定版本链接保留。切换工作区继续经过草稿、助手和视图保留屏障；不改变画布、镜头、候选与选用的业务身份。镜头列表中的「查看场次」是查看范围，不能被理解为批量迁移镜头或画布。

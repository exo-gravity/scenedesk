## 查看

[打开双模式效果图](http://127.0.0.1:4311/#/layouts/)。点击「分镜模式／自由画布」切换，可进入全屏查看；自由画布下再用「画布视野」选择全场总览或局部制作，视觉规范页也提供入口。全场图展示咖啡厅的六个镜头与共用参考；局部图展示 SH04 拿起旧钥匙及候选 A／B。这是两种制作模式的三个视野示意，不是第三种制作模式。

本轮使用内置 image_gen，延续已有深灰与暖杏色视觉及人物、场景参考。效果图中的控件是静态设计，本地查看页实际支持图片切换、全屏、原图查看和键盘关闭。场次生产页尚未实现图中的双模式。

## 共同框架

- 顶部统一为「旧钥匙 / 第1集 / 咖啡厅」，紧接「镜头制作／剪辑」；右侧为「预览整场」和具体版本的「审阅稿 v1 · 待修改」。
- 第二行提供同一位置的「分镜模式／自由画布」切换，素材、历史、助手保留按需入口。
- 当前场次、镜头和候选属于共同业务数据；局部两图表现正在查看 B，A 仍是当前采用；新增全场图没有选中节点，不展示局部输入区。
- 正在查看、采用、剪辑实际使用、固定稿审阅分别存在；新尝试基于 B 创建草稿，不覆盖 A／B，也不修改剪辑或固定稿。

用户查看效果图后确认：两种模式覆盖整个场次。第一版每场一张自由画布，承载多个镜头与共用参考；分镜模式的当前镜头详情和自由画布的当前节点编辑，都是场次内的局部焦点。

此前 v5 两张图主要展开 SH04，容易被理解为单镜头工作区。本次已补充 **v6 全场画布总览**：SH01–SH06、SH04 候选 B、人物／场景共用参考和笔记并存。无选中对象时不常驻生成输入。图中的历史引用曲线只解释素材来源，不按顺序连接镜头，也不触发整图执行；草稿可编辑引用与已执行来源的区分以 18 为准。查看页默认显示总览，可切到局部图；这不要求正式产品每次都把全部内容挤进视口。

## 两种模式的信息组织

| 分镜模式 | 自由画布 |
|---|---|
| 当前镜头的大画面为主要视觉焦点 | 多个独立参考与结果节点同时可见 |
| 右侧集中参考、提示词及生成参数 | 选中节点附近出现工具与新尝试输入区 |
| 底部分镜条保留全场顺序，候选选择与分镜条区分 | 镜头导航收起，画布位置与连线不决定镜头顺序 |
| 快速查看与切换镜头、比较候选 | 自由摆放、整理来源、从结果继续创建分支 |

分镜图采用先前「聚焦制作」的布局方向，让每种模式有清楚的使用重点；这是本轮可评估的设计提案，不将三种历史效果图作为必须再做的一次三选一。

画布参考 TapNow／LibTV 已核对的独立节点、局部工具及继续创作机制，详见[交互设计](scene-canvas-interaction-v0.1.md)与[来源记录](../research/2026-09-09-scene-canvas-interactions.md)。本轮将助手收起，使直接操作的空间与密度清楚可见；助手仍按需打开，没有取消对话入口或新增自主执行能力。

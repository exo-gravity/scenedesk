## 三档的取舍

| | 优点 | 代价 | 左基准数量 |
|---|---|---|---|
| **A 今天** | — | 四套基准、空态割裂、重复入口 | 4 |
| **B 250** | 一条基准贯穿全页；与两个参考产品一致（同类页面只有一条左基准） | 正文跑满内容区（1449 视口下约 1155px），**长文行宽偏长** | **1** |
| **C 273** | 保留阅读栏宽（1120，接近适合阅读的行宽） | 页头与标签页要跟着正文列内缩，**页面级左边界消失** | 2（相邻） |

**建议**：若剧本正文被视为**阅读材料**（当前确实如此 —— 空态文案是「与项目成员一起阅读」），选 **C**；若更看重整页骨架整齐、且正文多为短稿或表格，选 **B**。

| 文本 | 更多中进入文本分类，详情提供原文件下载；未宣称实现文本预览编辑器 |
| 读取失败 | 资产、媒体列表分别显示 503 错误和重试，恢复成功；不把失败显示成空库 |
| 响应式与键盘 | 1366×900、1280×600 深色、390×844、320×740；修正窄屏项目导航滚动，页面无横向溢出；更多菜单键盘及关闭后焦点返回 |

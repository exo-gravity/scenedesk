# 分镜助手整合验证

2026-09-11。当前范围见 [38](../../../docs/implementation/38-first-release-scope-review.md)，实现见 [41](../../../docs/implementation/41-generation-assistance.md)。这是显式本地测试适配器的业务链路验证，不是真实模型质量或部署验收；没有付费调用。

使用已构建的生产网页 `127.0.0.1:4311`、实际业务 API、持续 PostgreSQL 和独立受限 generation worker。同源请求没有 Origin 适配。独立技术项目不复用其他 agent 正在编辑的内容。显式准备脚本建立 test_fixture 能力；迁移0023–0027应用后总计28条，API角色复验通过。worker没有迁移、API或身份凭据。

- [提交回执恢复](verify-execution-recovery.js)：实际Unicode选区、明确场次上下文、双模式草稿保持；1次创建计划、1次执行，服务端真实202提交后只丢弃客户端回包。worker暂未启动，刷新及模式切换通过GET找回同一queued任务，镜头数仍为0。1512／1366／390边界通过，0 pageerror、0 API 5xx。
- [修订与采纳](verify-proposal-adoption.js)：启动实际受限worker，读取succeeded任务和持久Proposal r1；人工编辑、1次PUT保存r2，再1次POST明确采纳，仅此时创建一个镜头。原始建议和来源保留，再次刷新恢复已采纳状态；0额外执行请求、0 pageerror、0 API 5xx。
- [首页退出清理](verify-home-logout-cleanup.js)：新文档仅加载首页、未加载懒加载场次页面时，实际退出登录清理1条当前会话的历史助手记录，剩余0条，服务端会话读取返回401。初版脚本在退出触发的reload期间读取IndexedDB导致执行上下文销毁；修正为等待登录入口后完整v2通过。
- 完整整合检查：60项单元，160项数据库测试通过，无失败、取消或跳过。具体结果与日志摘要见[results.json](results.json)。既有媒体流程未改动，本提交仍需远端全媒体回归。

五张最终截图均已查看：回包丢失瞬间、三个宽度的queued恢复、实际采纳结果。回包丢失截图捕获核对请求中的加载态；它不代表最终保存状态。窄屏只验证当前助手与列表可用布局，不宣称完整移动端画布。

最初恢复脚本在实际请求完成前断言回执变量，随后过早解除route，记录为失败。其确实创建的唯一queued技术任务经过实际API明确取消，未分派；脚本修正为等待回包处理完成后，使用新的明确计划重新完整执行，以上通过结果来自v2。历史失败没有计入通过。

这些脚本记录本次明确技术夹具身份，用于复核该环境；重新准备环境时需替换其中项目/场次/任务ID，不能作为生产用户操作脚本运行。

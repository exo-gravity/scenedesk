# 制作专项 v0.4 · 页面与交互检查

日期：2026-09-10。范围：独立本地设计原型；用 Vite 生产构建在 4312 检查实际样式，再保留 4311 供用户查看。没有调用模型、保存服务器数据或真实媒体编辑。

## 结果

- `npm run build`：通过，包含前后端 TypeScript 检查及 Web 生产构建。
- `npm run ui:check`：通过，14 个已迁移文件；检查源码规则和选定色对，不等于完整无障碍认证。
- [交互走查](checks.json)：37 项通过；覆盖剧本来源与采纳、音轨选择、字幕区间、固定旧稿、时长影响、资产引用、离线、二次冲突、导航往返和紧凑布局。
- [最终字幕样式复核](caption-checks.json)：2 项通过，明暗主题中的字幕内容样式相同，未出现页面脚本错误。
- 视觉检查：1512×982 与 1366×768；右侧长内容独立滚动，剧本正文内部滚动。紧凑声音面板经过鼠标滚动可到达完整固定入口，冲突对照占实际布局空间。

[走查脚本](walkthrough.js)／[运行记录](walkthrough-output.txt)；[字幕样式脚本](caption-visual-check.js)／[运行记录](caption-output.txt)。这些是设计验证记录，不挂入正式业务测试或生产 AT。

## 检查发现及修正

1. 剧本框继承主题的自动增高行为，压住正式依据区域：显式关闭自动增高，使用固定工作区内滚动，并检查紧凑视图的入口位置。
2. 字幕核对选项在状态更新回调中读取事件对象，引发页面错误：在事件处理时先取值；重新完整走查通过。[首次错误记录](initial-failure.txt)保留作诊断证据。
3. 反复打开冲突对照可能重置手动合并：展开后入口禁用；二次冲突及读取新版均保留合并内容。
4. 浅色复选框继承暗色底，以及字幕随工作台主题反色：复选框改用现有语义色；字幕采用独立媒体颜色，主题切换保持一致。

最终仅修正字幕颜色后，补做目标样式复核并重新截取声音／字幕页；未再次重复完整业务走查。最终源码检查与构建通过。

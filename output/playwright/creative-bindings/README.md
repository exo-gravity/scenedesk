2026-09-11，本机人工导入／mock 模式，使用明确的技术夹具，不含模型效果或真实用户验收。

- `verify-scene-shot.js`：实际固定造型、声音、道具、参考保存与独立覆盖。

- `verify-conflict-recovery.js`：双标签页、真实 412、刷新恢复、人工核对合并，保留成对造型／父版本与另一人的声音及道具位置，保存后不再恢复旧草稿。
- `verify-project-settings.js`：剧目默认资产、独立项目版本的样片修改、刷新恢复及提交。

# AI 对话侧栏实际 UI 验收

本目录记录 2026-09-15 的实际 Chromium UI 操作、生产构建截图与只读持久化证据。它是独立合成业务夹具，不是用户的「旧钥匙 · 完整演示」，也不是付费模型质量验收。

## 环境与执行方式

- `serve.ts` 启动独立 PostgreSQL、MinIO、HTTP API、媒体处理与技术助手 worker；页面使用不可变 Vite 生产构建。
- UI 操作通过 CUA 浏览器完成，未用 API 或 JavaScript 注入替代点击、编辑、发送或采纳。
- `capture-evidence.mjs` 只读核对本次夹具的精确容器标识和数据库 schema，导出计划、任务、固定引用链、画布摘要及去敏化请求记录；不导出会话、CSRF、存储授权或连接密码。
- 运行 ID：`3ae7e622-a7eb-4b15-8796-0ebcb3cfafd1`。运行所需凭据和资源登记仅在被忽略的 `.runtime/` 中；本目录的 `fixture.json` 只有合成标识与可公开测试路径。
- 验收页面为 `localhost:4347`。测试窗口覆盖 1280×800、1280×600、390×844。未宣称 Safari、Firefox 或原生移动端验收。

## 已实际完成的流程

| 流程 | 观察到的结果 |
| --- | --- |
| 无选择直接聊天 | 无节点选择、无附件，连续发送三轮中文讨论；固定历史来源分别为 0、1、2 条。普通续聊不出现显式引用条。 |
| 键盘输入 | Enter 发送，Shift+Enter 换行；发送后仍聚焦输入区。临时本机写入期间只读，避免禁用导致失焦。 |
| 参考选择 | 从输入区搜索钥匙节点，添加缩略图参考；展开用途选择为道具，嵌套下拉未导致外层关闭。 |
| 新话题 | 保留未发送中文、参考和模型；刷新后仍为空的新话题，旧三轮只在历史可见；切换本身无模型执行。 |
| 历史和引用 | 查看原固定讨论后聚焦对应结果；明确引用显示原文摘要，取消后回到当前输入；历史查看不改变引用。 |
| 提示执行 | 明确准备固定计划，再点击执行本地助手；刷新后仍读取同一结果。 |
| 建议应用 | 选择指定画布草稿、核对差异、取消后未修改；明确替换保存为 r3，随后另一次明确追加保存为 r4。没有媒体生成或自动采用。 |
| 过期参考恢复 | r2 附件遇 r3 画布时拒绝发送，保留原文字且未创建计划；核对正文未变的差异后确认更新，发送成功。 |
| 核对焦点 | 应用差异与参考差异聚焦对应 region；取消、确认参考和应用完成均返回输入。 |
| 分镜任务 | 从对话进入分镜子任务，选择剧本修订及整篇原文，明确本地执行；编辑提案为第2版并明确采纳，分镜台实际新增1镜。 |
| 往返保留 | 从分镜任务返回对话、画布/分镜台切换、助手开合，原未发送文字及参考保留。助手开合前后 `translate(36px, 30px) scale(0.8)` 一致。 |
| 场次隔离 | 原场次未发文字保留；另一空场次新建独立画布，首次准备提示自动选唯一目标，刷新仍保留该场次的提示草稿。 |
| 默认目标竞态 | 实际复现过“切换成功却误报未保留”；修复后在全新画布首次进入提示任务，无误报，模型和草稿刷新一致。 |
| 尺寸与主题 | 浅色、深色、390px 窄屏和600px矮窗口实际检查；输入与发送可见，页面无水平溢出。参考菜单位于窄屏范围内。 |

## 阶段修正与最终复验

验收中发现并修正了重复输入边框、模型标签对齐、发送失焦、历史与核对区域定位、默认目标竞态。独立审查另发现未发送的提示任务往返会丢失讨论承接，增加绑定原固定请求身份的本机恢复与行为回归。

用户随后提供 LibTV 与 Reelay 参考并明确要求优化完整侧栏。最终采用轻顶部、连续消息流、统一底部输入：参考和明确引用在框内上方，正文居中，模型与必要选项在底行；执行记录和已应用差异按需展开。

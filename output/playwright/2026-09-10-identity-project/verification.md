# 身份与项目基础浏览器走查

2026-09-10。环境：本机 PostgreSQL、独立运行及身份角色、真实 HTTP/JWKS/RS256 的本地身份模拟器；没有模型调用。操作使用 Playwright CLI，页面走真实 API。

| 场景 | 实际结果 |
|---|---|
| 匿名进入 → 登录 | 跳转本地 OIDC 后返回；界面标明本地测试身份 |
| 创建工作室 → 创建项目 | 写入真实工作室与项目；创建者成为所有者、指定成员成为项目负责人 |
| 保存剧目设定 → 刷新 | 已保存内容恢复，项目上下文保持 |
| 两个页面编辑同一项目 | 第二页先保存；第一页旧版本提交返回 412，其输入保持，显示服务器版本；明确核对基线后可保存 |
| 归档 → 恢复 | 归档后编辑入口不可写，恢复后重新开放 |
| 创建邀请 → 离开再回来 → 撤销 | 列表保持邀请状态且不暴露令牌；撤销后显示已撤销；未发送邮件 |
| 1366×900 开发页面 | 检查空态、项目表单、保存冲突和成员管理 |
| 1512×982 构建产物 | 通过 Vite preview 读取同一数据库，主题与内容绘制正确；preview 4312 只做读取，业务写入仍要求配置站点 4311 |
| 390×844、320×740 | 无横向溢出，表单与操作可纵向滚动；320px 测得内容宽度 313px，页面宽度 320px |

截图：[空项目](01-empty-projects.png)、[保留输入的冲突](02-conflict-keeps-input.png)、[邀请撤销](03-members.png)、[小屏表单](04-mobile.png)、[构建后的项目](05-built-project.png)、[320px 构建页面](06-built-mobile.png)。第一张为标签对比度修正前的空态，最终样式以构建图为准。

开发走查发现入口文件热更新重复创建 React root，已将根组件移到单独模块修复；后续完整导航与构建产物无此异常。401（未登录）和 412（刻意制造版本冲突）是预期响应，不被计为成功业务请求。截图均经过查看，未包含有效邀请令牌或数据库凭据。

多身份越权、邀请接受、所有权／负责人交接、伪造签名和重复回调由真实 PostgreSQL 集成测试覆盖。未声称本轮已做真实团队协作、模型、媒体或完整 MVP 验收。

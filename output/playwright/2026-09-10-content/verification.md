# 手工剧本与内容结构浏览器验收

2026-09-10；本地真实 PostgreSQL、受限 API 角色、OIDC 测试身份；Chromium，实际点击／填写页面。使用上一切片的“幕序验收工作室”和“旧钥匙”项目，未调用模型。

1. 录入含中文、emoji 和换行的剧本，尚未提交时刷新；重新打开出现本地恢复提示，选择恢复后保存为第 1 版。截图：[本地恢复](01-local-recovery.png)。
2. 创建“第一集 · 旧钥匙”及“01 · 旧公寓重逢”，保存梗概、时间地点与连续性说明。创建镜头 01A，填入意图、动作、4.2 秒计划、机位、入口／出口、台词和表演要求；在只读剧本中选择原文并添加引用，保存成功。截图：[内容工作区](02-workspace.png)。
3. 仅将镜头改名为“01A · 入屋”，要求历史仍为第 1 版。只读数据库核对：Shot revision=2、要求 number=1、history_count=1、duration_us=4200000。截图：[固定要求历史](03-fixed-history.png)；后续补充显示入口／出口和备注。
4. 标签页一编辑意图并保留本地；标签页二保存另一意图；刷新标签页一、重新打开并选择恢复。界面展示服务器版本 3 的新意图，编辑框保留标签页一原输入，保存禁用；明确核对基线后可提交，随后形成新要求版本。截图：[恢复后的版本冲突](04-recovered-conflict.png)。
5. 320×740 窗口检查结构与镜头，实测 documentWidth=320、mainWidth=313，无横向溢出。截图：[小屏场次](05-mobile-320.png)。1512×1000 布局也已检查。
6. 最终构建通过 Vite preview 4312 读取同一真实 API，检查 CSS 提取后的[工作区](06-built-workspace.png)及包含入口／出口的[要求历史](07-built-history.png)，控制台无错误或警告。此预览仅做读取，写操作继续使用配置的 4311 来源。

设计原型与浏览器测试期间切换 Git 分支产生的旧 Vite 连接错误不作为业务结果；重新加载后的页面完成上述验证。归档、完整重排、RLS、不可变历史和失效游标还由真实数据库集成测试验证。

# 模型选择器 UI 验收

产品源：`4768f72ab1e9777821878c335da80eab63c41eea`。使用同一不可变 Vite 生产构建，经 CUA 实际操作 Chromium；这是一份手动端到端 UI 验收记录，不是可自动重放的浏览器测试，也不是模型执行验收。

`serve.ts` 创建自己的 PostgreSQL、受限数据库角色、真实 HTTP/API 与合成项目，使用与产品一致的页面和本机草稿机制。没有存储、队列或供应商 executor；正常能力列表来自实际数据库，异常场景仅受控替换 capability GET 的响应。所有模型明确为本地 fixture，未修改用户演示或其他项目。菜单正常请求包含 `?limit=100`，控制钩子按 pathname 匹配。
